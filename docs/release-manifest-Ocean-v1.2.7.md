# 《海战 OCEAN》Ocean-v1.2.7 正式发布清单

> 产品版本：Ocean-v1.2.7  
> npm version：1.2.7  
> 稳定代码基线：Ocean-v1.2.6  
> 规则：rule-v1.8（未修改）  
> 页面流程：page-flow-v2.0（未修改）  
> Socket Protocol：2.0（未修改）

## 1. 版本边界

Ocean-v1.2.7 只进行手机端 UI 适配，不调整任何作战单位、伤害、资源、地图参数、胜负条件、机器人策略、三人同步结算、消息保密边界或服务器事件协议。

继续完整保留：

- 1v1 联机、1v1 人机和三人 FFA；
- 10×10、12×12、15×15 三档动态地图；
- v1.2.6 五类私人标记、三人一次同步行动与独立防守方结算；
- 战况 / 私人情报 / 系统三个频道；
- 断线重连、最终齐射、声音设置和 Render 部署。

## 2. 手机端适配

- viewport 启用 `viewport-fit=cover` 与 `interactive-widget=resizes-content`。
- 顶栏、正文、底部工具条、Toast 和弹窗适配刘海屏及底部手势安全区。
- 首页、等待、部署、掷骰、正式对战、终局结算和复盘统一适配 320～700 px 窄屏。
- 手机地图使用 42 px 触控格和横向滑动；手机端强制 `zoom: 1`，不叠加桌面三人 0.85、15×15 0.9、三人 15×15 0.765 的视觉缩放。
- 战斗状态栏改为普通流式卡片；地图切换条单独黏附在全局顶栏下方，避免两者重叠。
- 行动面板保持底部抽屉结构，展开高度限制为最多 64dvh，并支持内部滚动。
- 五类私人标记工具横向滑动；点击格子添加，电脑右键或手机长按 550 ms 删除。指针移动超过 10 px 时取消长按，防止地图滑动误删。
- 实时播报保持小尺寸、可点击关闭；手机端占满安全宽度，不覆盖半屏。
- 规则与声音设置在手机端以底部弹层呈现，操作按钮保持在可见安全区域。
- 横屏且高度不超过 520 px 时，顶栏退出黏性定位，地图切换与弹层使用紧凑高度。

## 3. 明确不变内容

- `docs/rule-v1.8.md` 不变；
- `docs/page-flow-v2.0.md` 不变；
- `docs/socket-protocol-v2.0.md` 不变；
- 服务端战斗规则与结算逻辑不变；
- 桌面端 0.85 / 0.9 / 0.765 地图缩放不变；
- `ocean-theme.mp3` 路径与播放逻辑不变。

## 4. 音乐文件

正式发布前应确认以下文件存在：

```text
public/assets/audio/music/ocean-theme.mp3
```

从 Ocean-v1.2.6 升级时，将原有 `ocean-theme.mp3` 原样复制到 Ocean-v1.2.7 的相同相对路径。音乐文件不参与源码规则变更；若缺失，游戏与内置合成音效仍能运行，但背景音乐不可播放。

## 5. 自动验收

新增 `test/ocean-v1.2.7-mobile.test.js`，覆盖：

- 手机 viewport 与安全区；
- 42 px 地图触控格及移动端禁用桌面缩放；
- 状态栏、地图标签与行动抽屉的层级关系；
- 标记工具横向滑动与手机长按删除；
- Toast、底部弹层及横屏紧凑模式；
- 规则 v1.8、页面流程 v2.0、Socket 2.0 保持不变。

正式验收命令：

```powershell
npm ci
npm run acceptance
```

# Ocean-v1.5.5 发布清单

基线：Ocean-v1.5.4。npm：1.5.5。规则：rule-v1.8。页面流程：page-flow-v2.1。Socket：2.1。

## 本版范围

1. 选择任意可用行动后自动切换到当前敌方地图；首回合雷达明确提示选择扫描区域左上格。
2. 行动确认框显示回合剩余时间；回合、房间阶段或行动状态变化后自动关闭旧确认框。
3. 最新行动反馈完整显示4.5秒后折叠为42px单行，可由玩家手动展开或收起。
4. 右侧单位行动卡默认折叠，标题保留单位状态、生命值和可用行动数；选中行动时自动展开来源单位。
5. 选择行动及点击敌方目标时自动关闭战斗日志，避免覆盖目标区域。
6. P01～P06页面切换时将页面和主应用滚动位置重置到顶部。

## 保持不变

- 规则、伤害、生命值、弹药、地图尺寸、人机策略和三人同时结算逻辑不变。
- Socket 2.1事件、服务器权威状态与信息投影边界不变。
- v1.5.4第二批48项素材、v1.5.3满幅沙盘、v1.5.2第一批素材及v1.5.1经典按钮风格完整保留。
- 手机端继续沿用既有响应式结构，折叠反馈和单位卡提供相同语义与操作入口。

`npm run acceptance` 通过：382项测试，pass 382 / fail 0 / skipped 0；53组生产音效 OGG/MP3 校验、环境、语法、DOM交互、联机与整局流程均通过。专项回归覆盖版本标识、自动切图、确认框失效、确认倒计时、反馈折叠、单位卡折叠、日志避让和页面滚动重置；完整结果写入 `docs/acceptance-v1.5.5.txt`。

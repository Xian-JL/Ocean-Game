# Ocean-v1.5.1 发布清单

## 版本边界

- 产品版本：`Ocean-v1.5.1`
- npm SemVer：`1.5.1`
- 规则版本：`rule-v1.8`
- 页面流程：`page-flow-v2.1`
- Socket Protocol：`2.1`
- 代码基线：`Ocean-v1.5`

本版只修复正式对战页的桌面布局与非行动面板按钮外观，不修改服务器规则、数值、AI、信息投影、移动端交互或联机协议。

## 修复项

1. 完整地图
   - 舰桥工作区按“最近行动反馈 / 剩余地图区”自动分配高度。
   - 方形地图以容器真实高度和宽度中的较小值为上限。
   - 10×10、12×12、15×15 不再被 112px 底部控制台覆盖。
   - 透视角收敛为 2.5°，并保留 3.5% 的边缘安全缩放。

2. 经典按钮风格
   - 地图切换、左侧情报入口和底部控制台使用 v1.4.2.2 的中文字体、圆角细边框、悬停与选中反馈。
   - 确认按钮恢复青色主按钮风格，投降按钮恢复危险操作色。
   - 右侧行动面板完整保留 v1.5 的坐标读数、舰队状态、武器卡片与滚动布局。

3. 保持项
   - 三种地图、三种主题、五种强调色。
   - 双人联机、标准/新手/专家机器人、三人 FFA。
   - 首回合雷达、普通行动、最终齐射、重连和再来一局。
   - 900px 及以下手机布局。

## 验收要求

- 1366×768、1600×900、1920×1080 下地图四边与最后一行、最后一列均位于底部控制台上方。
- 最近行动反馈存在和不存在时都能完整显示地图。
- 右侧行动面板结构与 v1.5 一致。
- 完整自动化测试、语法检查、音效校验和发布一致性检查通过。

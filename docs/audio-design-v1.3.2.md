# 《海战 OCEAN》音效设计 v1.3.2

> 对应产品：Ocean-v1.3.2  
> 变更范围：在 v1.3.1 差异化音色基础上增强音效引擎；不修改规则、数值、教程、人机难度、页面流程或协议

## 1. 设计目标

1. 操作反馈明显：从 v1.3.1 的多层音调组合进一步升级为“总线化”渲染，统一处理响度与防削波。
2. 操作可辨识：十种战斗行动、部署编辑、房间、标记、教程与系统状态继续使用独立音色。
3. 不泄露情报：音效只表达玩家有权知道的事件；隐藏武器固定播放“已执行”音，不绕过消息投影规则。
4. 保持低成本：全部音效继续由 Web Audio API 实时合成，不新增第三方音效包和网络请求。
5. 控制干扰：新增并发上限与压缩器，快速连点不会产生节点风暴或爆音。

## 2. v1.3.2 引擎增强（P0-A）

### 2.1 主音频链

```text
effectsBus ─┐
            ├─→ DynamicsCompressor → masterGain → audioContext.destination
musicBus  ──┘
```

- 所有音效节点（音调与噪声）输出到 `effectsBus`，不再直连 `destination`；
- 压缩器参数：`threshold -12 dB`、`knee 20`、`ratio 4`、`attack 0.003 s`、`release 0.25 s`；
- `musicBus` 预留给后续背景音乐接入 ducking；P0 阶段背景音乐仍走 `Audio` 元素自身音量；
- 浏览器不支持 `createDynamicsCompressor` 时自动回退直连，不影响功能。

### 2.2 并发上限

- 同时活跃音效节点上限 12 个（`MAX_CONCURRENT_EFFECTS`）；
- 达到上限时新音效被忽略；音效按预计时长自动释放计数。

### 2.3 版本标识

- 音频库内部版本 `EFFECT_LIBRARY_VERSION` 升级为 `"2.0"`；
- 所有音色定义（`PATTERNS`）、播放时机与保密规则与 v1.3.1 完全一致。

## 4. 保密约束（不泄露情报）

- 潜射导弹、核弹和震爆弹始终播放固定的“行动已执行”声音。
- 上述声音不因命中、未命中、目标类型、目标生命值或伤害量变化。
- 普通攻击的行动音在服务器确认行动合法并成功提交后播放；其声音本身不编码目标身份或生命值。
- 攻击方仍只能从现有合法播报获知“命中”等允许信息；防守方自己的受伤反馈不投射给攻击方。

因此，差异化音效不会形成新的情报侧信道。

## 5. 播放规则

- 本地操作只有在操作合法且真正生效后播放部署、标记或锁定音。
- 房间创建、加入、准备、行动提交等服务器操作在成功响应后播放。
- 打开确认框可先播放警示或面板音，最终确认与取消再分别播放确认音和取消音。
- 单一操作不再叠加无意义的通用点击音；仅无法识别语义时才回退到基础点击声。
- 浏览器不支持完整噪声节点时，自动退化为合成低频音，不影响游戏运行。

## 6. 音频资源与音量

- 操作音效不需要文件，集中定义于 `public/js/audio-system.js`。
- 背景音乐仍放在 `public/assets/audio/music/ocean-theme.mp3`。
- 音效与背景音乐继续独立开关、独立调节；本版不改变既有设置入口和保存逻辑。

## 7. 验收标准

- 十种战斗行动具有十个不同的声音标识；音效与音乐开关、音量调节行为不变。
- 新增压缩器母线与并发上限逻辑存在且可回退；无外部音效依赖。
- 音效关闭时不创建播放节点；音量缩放仍正确。
- 隐藏武器不根据结算结果选择声音（自动化测试覆盖）。
- 完整自动化测试、双客户端整局、手机端和既有规则测试全部继续通过。

# Ocean-v1.6.1 发布清单

基线：Ocean-v1.6.0。npm：1.6.1。规则：rule-v1.8。页面流程：page-flow-v2.1。Socket：2.1。

## 本版范围

### 战术信息层级

- 顶部战斗状态条加入明确的实时在线、同步中和连接中断状态，并压缩非核心占位。
- 右侧行动面板在单位卡片上方固定“01行动、02目标、03确认”指挥链。
- 十种行动按服务器安全视图派生为可用、受限、耗尽/失效三档；选中和可用来源优先展示。
- 新UI图仅作为装饰层，按钮文字、焦点、禁用状态和原有事件继续由HTML与客户端逻辑负责。

### 海域分层

- 综合视层保留水面与潜航单位的协同关系；水面视层强化海面高光、泡沫和舰体阴影；潜层视层强化焦散、深度雾、颗粒和折射。
- 切换视层使用声呐环、下潜尾波或上浮尾波，并在820毫秒后清理；减少动画时缩短至80毫秒。
- 敌方沙盘只应用中性海面装饰，不读取或渲染额外敌方单位数据。
- 自动/高画质/流畅档继续生效；流畅档关闭泡沫、颗粒、折射及连续精灵动画。

### 美术资源

- 第一批与第二批既有2.5D素材继续保留。
- 新增60项UI素材和9项海域分层素材，全部从交付PNG转换为透明或无损视觉用途的WebP独立文件。
- 原始交付压缩包不进入运行目录；浏览器只请求实际使用的优化资源。

### 四档视口

- 电脑（≥1001px）保留左侧日志、中央沙盘、右侧行动和底部控制台的完整驾驶舱结构。
- 横屏平板（1001–1280px横屏）压缩顶部与侧栏但保留三栏结构。
- 大型竖屏平板（701–1000px竖屏）使用中央地图加互斥抽屉。
- 主流手机（≤700px）保留44px触控目标，并在己方地图快捷条提供视层轮换。

## 冻结边界

- 不修改rule-v1.8规则、数值、地图、伤害、资源消耗、AI策略和终局流程。
- 不修改Socket 2.1、状态版本、服务器权威结算、客户端安全投影与三人隐私边界。
- `move`、`patrol`、`end_turn`等交付图标不映射为游戏行动。

## 验收

执行 `npm run acceptance`。专项回归覆盖69项新素材、UI装饰边界、三步指挥链、行动分级、三种海域环境、切层过渡、敌方安全视图、画质降级、减少动画和四档视口。53组生产音效双格式校验通过，433项自动化测试全部成功；最终结果见 `docs/acceptance-v1.6.1.txt`。

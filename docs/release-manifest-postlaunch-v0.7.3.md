# 《海战 OCEAN》postlaunch-v0.7.3 发布清单

> 版本：0.7.3  
> 阶段：postlaunch-v0.7.3  
> 玩法基线：postlaunch-v0.6.2  
> 规则：rule-v1.4  
> Socket Protocol：1.5

## 范围

v0.7.3 只重构正式对战中的行动选择、攻击范围表达、地图格状态和己方舰队状态展示，不修改服务器游戏逻辑。

## 完成项

- 行动面板按舰艇攻击、潜航武器、舰载系统分组；
- 所有 10 类现有行动继续保留原入口和服务器合法性判断；
- 首次雷达阶段增加独立任务卡，完成第一名敌人的雷达后仍按 rule-v1.4 处理另一名敌人；
- 三人局直升机双目标状态明确显示同时作用的敌人和单次资源消耗；
- B / C 两张敌方地图在直升机选择时同步显示同一行 / 列范围；
- 地图格增加统一 `data-cell-state`：公开命中、公开未命中、结果未知、私人标记等；
- 地图格增加统一 `data-range-state` 与 `data-intel-state`；
- 潜射导弹和核弹继续使用“结果未知”视觉，不展示命中推测；
- 己方舰队面板直接显示当前 HP、受伤、瘫痪、沉没以及特殊资源；
- 两艘摩托艇 UI 行动状态优先使用仍存活的同类型来源单位；
- 操作确认框减少规则说明，只保留完成提交所需的信息；
- v0.7.2 多地图折叠、独立敌方记录和三人回合进度全部保留。

## 明确未修改

- 舰船数量和数值；
- 伤害、攻击范围和弹药规则；
- 三人每回合分别对两名敌人操作的规则；
- 直升机多目标结算规则；
- 最终鱼雷多目标规则；
- 首次雷达规则；
- 90 秒共享回合计时；
- 瘫痪、淘汰、胜负；
- 隐藏信息投影；
- 断线重连；
- 服务器权威模型。

## 验收

必须继续通过 v0.6.2 玩法逻辑测试、v0.7.0～v0.7.2 UI 回归测试，并增加 v0.7.3 行动面板和战斗状态回归测试。

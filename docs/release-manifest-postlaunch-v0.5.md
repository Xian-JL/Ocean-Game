# Ocean postlaunch-v0.5 发布清单

- 基线：postlaunch-v0.4，固定 12×12 地图与同一单位格一次伤害资格。
- 部署：移除 3×3 雷达部署物，恢复为 7 个作战单位与 3 枚诱饵鱼雷，共占 28 格。
- 开局雷达：航空母舰自带；每名玩家的首个行动回合强制选择完整 4×4 区域，只返回是否存在敌方布局。
- 驱逐舰：两艘驱逐舰共享目标记录，同一坐标最多被驱逐舰攻击一次；其他武器不占用此记录。
- 核弹：不向发射方或公开记录报告命中、未命中、目标身份或伤害；防守方正常看到己方状态变化。
- 海盗船：2 点生命；成功命中作战单位时目标 −2、海盗船 −1；命中诱饵时海盗船受 1 点爆炸伤害；海盗船每次实际受伤使己方航空母舰联动 −0.5。
- 终局：双方无攻击手段后逐轮秘密选择一枚有效鱼雷，双方提交后同时结算，直至全部鱼雷处理完毕。
- 生命周期：赛后离开方先注销席位与 Socket 绑定，后续连接关闭不会令留下的房主进入断线暂停。
- 协议：Socket.IO 1.3，新增 `final-salvo:submit`。
- 文档：`rule-v1.2.md`、`page-flow-v1.2.md`、`socket-protocol-v0.6.md`、`future-roadmap.txt`。
- 验收：`npm run acceptance`，全部自动化测试必须通过。

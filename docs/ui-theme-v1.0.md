# 《海战 OCEAN》界面主题设计 v1.0

> 对应产品：Ocean-v1.3.2  
> 规则依据：rule-v1.8、page-flow-v2.1  
> 变更范围：仅个人化外观；不修改对局规则、信息投影或 Socket 协议

## 1. 设计目标

1. 个性化外观：玩家可自选界面主题与强调色，仅保存在当前浏览器。
2. 零侵入：主题切换不改变任何组件结构、类名与服务器行为。
3. 可持续：以“色板 → 语义 → 旧变量别名”三层令牌为地基，未来新增主题只需追加覆盖块。
4. 可访问性：三套主题均满足文本对比要求，保留“减少动画”等既有设置。
5. 不泄露情报：主题与强调色是纯本机呈现，不进入 `room:state`、遥测或任何网络事件。

## 2. 设计令牌体系

### 2.1 分层

| 层 | 作用 | 示例 |
| --- | --- | --- |
| 色板 | 原始色值，仅供语义层与主题覆盖引用 | `--sea-950`、`--cyan-token`、`--line-rgb` |
| 语义层 | 组件引用的抽象语义，主题覆盖这一层 | `--surface-page`、`--text-primary`、`--accent-primary` |
| 旧变量别名 | 向后兼容 v1.3.1 及更早组件，自动跟随语义层 | `--bg-abyss: var(--surface-page)`、`--cyan: var(--accent-primary)` |

半透明颜色统一使用 RGB 分量变量派生：`rgba(var(--accent-primary-rgb), 0.08)`，主题与强调色变化时透明度派生自动跟随。

### 2.2 主题清单

| data-theme | 名称 | 风格 | color-scheme |
| --- | --- | --- | --- |
| `ocean-dark` | 深海暗夜 | 暗色（默认基线） | dark |
| `ocean-light` | 极地寒光 | 亮色 | light |
| `ocean-dusk` | 黄昏余晖 | 暖暗色 | dark |

主题覆盖块定义于 `public/css/main.css`，通过覆盖语义层变量生效，组件样式零改动。

### 2.3 强调色清单

| 值 | 名称 | 主色 | 派生（strong / soft / rgb） |
| --- | --- | --- | --- |
| `cyan` | 离子青 | `#63ddf5` | `#1ec6eb` / `rgba(64,204,236,0.12)` / `99, 221, 245` |
| `gold` | 荣耀金 | `#f4c25a` | `#d9a02e` / `rgba(244,194,90,0.14)` / `244, 194, 90` |
| `jade` | 翡翠绿 | `#59e0ac` | `#2fbf85` / `rgba(89,224,172,0.14)` / `89, 224, 172` |
| `crimson` | 赤焰红 | `#ff6b77` | `#e23b4c` / `rgba(255,107,119,0.14)` / `255, 107, 119` |
| `violet` | 极光紫 | `#bc8cff` | `#9660e8` / `rgba(188,140,255,0.14)` / `188, 140, 255` |

强调色以最高优先级（内联样式）覆盖 `--accent-primary`、`--accent-strong`、`--accent-soft`、`--accent-primary-rgb`；旧 `--cyan` 系别名自动跟随，现有组件立即生效。

## 3. 个性化设置入口

- 页面顶部新增“✦ 个性化设置”按钮，打开独立弹窗 `#personalize-dialog`。
- 弹窗包含两组互斥原生按钮：
  - 界面主题：深海暗夜 / 极地寒光 / 黄昏余晖（带预览色卡）；
  - 强调色：离子青 / 荣耀金 / 翡翠绿 / 赤焰红 / 极光紫（带圆形色点）。
- 选择即时生效并持久化；提供“恢复默认”（深海暗夜 + 离子青）与“完成”按钮。
- 移动端弹窗宽度自适应，窄屏主题单列、强调色三列布局。

## 4. 存储与首帧引导

| 键 | 取值 | 默认 |
| --- | --- | --- |
| `ocean.theme.v1` | `ocean-dark` / `ocean-light` / `ocean-dusk` | `ocean-dark` |
| `ocean.accent.v1` | `cyan` / `gold` / `jade` / `crimson` / `violet` | `cyan` |

- `public/js/theme-bootstrap.js` 在页面首帧、其余脚本执行前同步读取并应用已保存设置，避免刷新闪烁；该脚本不创建 UI、不发送网络事件。
- `public/js/app.js` 在运行时维护主题与强调色（`applyTheme` / `applyAccent`），存储键与首帧脚本一致。
- 存储不可用（隐私模式等）时静默回退默认值，不影响游戏。

## 5. 信息边界

- 主题与强调色是纯本机呈现偏好：不写入 `room:state`，不发送 Socket 事件，不进遥测。
- 不同浏览器标签页可独立设置主题，互不影响。
- 主题切换不改变任何命中、伤害、侦察或胜负结算结果。

## 6. 回归边界

- 所有既有页面（P01～P06、T01、O01～O06）在三套主题下结构、布局与交互不变。
- 既有 CSS 类名、`id`、`data-action` 与 `data-*` 属性不修改、不删除。
- 手机端 42px 触控格、地图缩放比例（0.85 / 0.9 / 0.765）、私人标记与战况日志保持不变。

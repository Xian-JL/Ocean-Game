## 当前子版本边界

`Ocean-project-rules-v0.4` 在已验收的 v0.1、v0.2、v0.3 基础上实现：

- 攻击方、防守方和公开行动记录的服务器端信息裁剪；
- 对局结束前的敌方部署、生命值、弹药、诱饵和震爆结果隔离；
- 对局结束后的完整部署、最终状态和内部行动记录复盘；
- 普通航空母舰沉没胜负及海盗船三种终局特例；
- 投降、连续三回合超时、断线超时和双方断线取消的纯规则接口；
- 双方无攻击手段检查、有效诱饵同时发射和齐射后生命值比较；
- 航空母舰沉没优先于终局鱼雷齐射的原子检查顺序；
- 上述内容的自动测试。

本子版本暂不实现房间、正式回合编排、计时、重连和正式界面，也不接入 Socket.IO 对局事件。底层 `resolveAction` 仍含秘密信息；正式服务只能使用 `resolveBattleAction`，并把每名玩家对应的安全数据单独发送。

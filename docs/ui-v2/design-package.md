# UI 2.0 设计与实现对照

## 视觉定义

“黑潮军械库”以原创建造舰坞作为首页主体，黑钢承托信息，蚀铜断刻标示层级，余烬承托主行动。海图保留独立冷色水体，避免整页同色发光。展示标题使用系统宋体回退，正文使用系统无衬线；OCEAN 主字标由原创 SVG 路径构成。未引入 LoL/Dota 素材或虚构的商店、排位与成长模块。

五个识别物分别落实为三种舰徽、左上 12px / 右下 4px 切角、铜色短刻与序号、十槽军械台、四种战果印章。舰艇本体复用已有透明素材与航母模块，保持真实占格。肖像仅取自己的实际行动来源，不把两艘摩托艇合并成共享生命值。

## 组件状态与交互

| 组件 | 空/默认 | 选中 | 受限/错误 | 提交 |
| --- | --- | --- | --- | --- |
| 出征区 | 三种真实模式与地图 | 描边、底刻与 radio 状态 | 连接与昵称原因 | 原 pendingRequest，禁止重复创建 |
| 武器槽 | 固定 1～9、0 | 铜楔、边界和勾号 | 固定槽不消失，原因由原 Model 返回并以 aria-describedby 关联 | 原模型禁用，资源事实即时更新 |
| 指令台 | 等待选择 | 行动、目标、实际来源 | 明示风险与未知应答；低高度摘要内部可滚动 | 按钮保留且显示正在提交 |
| 海图 | 未知与坐标 | 单格/区域/行列真实范围 | 不能选择时说明原因；私人笔记另用角标/线纹 | 选点仅草稿，按钮才提交 |
| 弹窗 | 钢面阅读区 | 可见焦点 | 原拒绝/同步文案 | 真实操作，不播放假进度 |

组件样板入口为运行后的 `/armory-lab.html`，包含三主题、状态、四章面、十种中性效果和高/流畅/减少动画。样板标明合成，不连接 Socket，不读取凭证。实际战斗可从训练营复现。

## 十行动配置

| 行动 | 几何/节奏 | 旧能力去向 | 权限边界 |
| --- | --- | --- | --- |
| 驱逐舰Ⅰ | 单脊、一次接触压力线 | 保留水花/冲击/碎屑 | 只表现合法 hit/miss 和真实己方变化 |
| 驱逐舰Ⅱ | 双脊、双段压力 | 保留较重水花/冲击 | 不扩大射程，不把命中当作确定伤害 |
| 海盗船 | 双向交叉切线 | 保留冲击/碎屑 | 自损/联动只按己方安全事实 |
| 摩托艇 | 短 V 尾迹 | 保留航迹与水花 | 两实例独立，不给无伤害目标扣血 |
| 潜射导弹 | 斜向密封弹体 | 保留 launch / torpedo trail | 攻击方隐藏真假同形、同资源与时长 |
| 核弹 | 裂核、聚合与局部压力环 | 保留 flash core / shock ring | 无全屏白闪，隐藏真假同输出 |
| 震爆 | 分段磁线与断续环 | 保留 EMP pulse / impact | 不暗示对手是否瘫痪 |
| 探测 | 双声呐环、统一区域 | 保留 sonar ping | 只给区域布尔结果，不点亮秘密舰格 |
| 雷达 | 方框与单向扫描刃 | 保留 radar sweep | 从真实起始格均匀覆盖 3/4/5 区域 |
| 直升机 | 沿行/列的长线掠过 | 保留 helicopter trace | 只按可见逐格结果，不新增可部署飞机 |

高档单格 96～128px，流畅 80～112px；普通流畅 440ms，核弹/雷达/扫射流畅 520ms。高档仍为 750～1400ms。流畅保留第二压力线和第二声呐环；降级优先减少装饰资产数量。单主效果、无历史队列、1800ms 取消边界和安全序号去重沿用原实现。

## 其他能力

爆炸、水花、尾迹、阴影、舰体伤损、残骸、瘫痪、鱼雷失效、海域焦散和真实切层水纹均保留。材质围绕新钢面组织，正文区不承受持续扫描。只保留一层环境持续运动；流畅、减少动画和后台停止环境。

己方 HP 数字即时更新，变化条与状态只响应安全差分。结算章面采用一次缩放/明暗落定；取消与平局使用中性结果音。声音仍由原安全事件拥有，ACK/同步不重复播放，迟到音频解码不补播。

## 证据限制

fire-mobile-frame-* 为真实训练开火的连续帧，nuclear-mobile-frame-* 为真实核弹试射，文件旁保存采集时刻和实际构建；核弹结果保持未知。不能用这些截图估计帧率。lab-nuclear-synthetic.png 明确为合成样板。真实正式雷达、训练开火/核弹、训练重来和退出已操作；完整十行动×两档×设备的视觉矩阵留待独立验收。

## 运行与复现

在项目根目录执行 npm ci、npm start，访问 http://127.0.0.1:3000。组件与中性效果样板为 /armory-lab.html，真实动作可从训练营进入。修改源代码后 npm run build；运行中的服务器应重启以读取新资源版本。npm run acceptance 会检查 3000 端口空闲，应先结束本次开发服务后执行。

# 性能与资源报告

## 已取得的数据

实际静态文件字节、gzip 压缩尺寸、运行美术增量和开发机 Node/OS/CPU 信息由 scripts/export-ui-v2.js 输出到 [resource-budget.json](resource-budget.json)。图像逐文件尺寸、透明状态与 SHA 位于 [generated-art.json](generated-art.json)。新增字体为 0 字节。美术大小自动测试已纳入最终基础回归。

浏览器为 Windows 上 Codex 内置浏览器，观察到 Chrome/155.0.0.0、DPR 1；属于模拟桌面/手机视口，不能代替 Android 或 iOS 真机。实际视口及加载的 CSS 构建地址记录在 screenshots/browser-environment.json。

静态 gzip 大小是文件分析，并非网络传输、冷缓存、首屏就绪或 LCP。截图和连续帧采集延迟也不是游戏帧率。当前未给出推测 fps、伪造 p95 或未采集的内存数据。

## 原始样本模板

每条样本需包含构建指纹、设备/CPU/内存/系统、浏览器完整版本、视口/DPR、主题/画质、网络/CPU 条件、是否冷缓存、阶段、时刻、原始值与失败原因。分位数使用 nearest-rank 上取整；不可删除慢样本或以平均值替代 p95。

已有单主短效、有限缓存、后台/减少动画取消和 1800ms 清理的自动覆盖，仍需在正式性能场景复核。此报告状态为“静态资源已记录，正式性能未测”。

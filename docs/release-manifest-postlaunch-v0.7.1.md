# 《海战 OCEAN》postlaunch-v0.7.1 发布清单

> 版本：0.7.1  
> 阶段：postlaunch-v0.7.1  
> UI：UI Design v0.7.0  
> 玩法基线：postlaunch-v0.6.2 / rule-v1.4  
> Socket Protocol：1.5

## 本版范围

v0.7.1 只修改舰队部署 UI 与交互表现，不修改服务器规则和部署合法性。

### 已完成

- 部署页改为进度条 + 舰队清单 + 12×12 地图 + 当前操作的现代工作区。
- 8 个单位与 3 枚诱饵按水面舰队、水下单位、战术装置分组。
- 地图标题栏加入最小化 / 展开按钮；折叠仅改变 DOM 展示，不向服务器发送事件。
- 当前对象显示完成状态、格数、旋转 / 撤回 / 撤销操作。
- 验证信息缩减为状态 + 首条必要错误，完整说明进入游戏说明。
- 随机部署、清空和准备操作重新分层。
- 移动端将部署地图置于首要位置，并重排舰队与操作面板。
- 保留 v0.7.0 首页、等待房间、Toast、Modal、Tooltip 与 Design System。

## 不变项

- v0.6.2 全部游戏逻辑。
- rule-v1.4。
- Socket Protocol 1.5。
- 服务器权威部署校验。
- 2 人 / 3 人玩法、三人双目标回合和两张独立敌方地图数据。
- 所有隐藏信息边界。

## 验收

发布前执行：

```text
npm ci
npm run acceptance
```

所有既有逻辑测试必须继续通过，并增加 v0.7.1 部署 UI 回归测试。

# Ocean-v1.4 战术海面界面设计

> 方案：D（真实海面 + 隐形坐标）  
> 规则：rule-v1.8（不变）  
> 页面流程：page-flow-v2.1（不变）  
> Socket：2.1（不变）

## 1. 设计目标

正式对战不再把持续可见的蓝色方格作为主要视觉。地图改为俯视真实海面，既有 10×10、12×12、15×15 单元格继续作为透明的逻辑与吸附层。视觉变化不得改变坐标、合法范围、目标确认、服务器结算或信息投影。

## 2. 图层结构

1. 航母舰桥环境：保留玩家坐在指挥席观察海面的 2.5D 框架。
2. 海面背景：无舰艇、无文字、无网格、无目标信息的俯视海洋图。
3. 隐形坐标：每格仍是原有按钮，继续携带 `data-coordinate` 和原事件。
4. 情报与单位：己方舰队、命中、未命中、导弹、雷达及五类私人标记。
5. 战术交互：悬停准线、坐标标签、5×5 局部网格、合法范围和目标预览。

## 3. 交互状态

| 状态 | 可见信息 | 不改变的逻辑 |
| --- | --- | --- |
| 默认 | 真实海面、极淡全局格线、必要的已知情报 | 全部坐标按钮仍存在 |
| 悬停/键盘聚焦 | 行列刻度、十字准线、坐标、目标附近 5×5 网格 | `A1`～`O15` 解析不变 |
| 选择行动 | 合法范围持续显示；悬停仍显示局部网格 | `legalTargetCells` 与 `previewCells` 不变 |
| 选择目标 | 目标范围使用高亮描边 | 继续提交既有目标对象 |
| 私人标记 | 标记叠加在对应海域格 | 仅写浏览器本地存储，不进 Socket |

## 4. 沉浸式布局

- 桌面与手机均只显示一张当前海域，地图接近全屏，不再并排压缩。
- 顶部地图标签在己方、敌方一、敌方二之间切换；切换只改变显示，不改变各海域独立记录。
- 桌面右侧设置“行动”和“消息”入口。行动面板、战况/私人情报/系统消息作为互斥覆盖侧栏，不永久占用地图宽度。
- 选择普通武器后自动收起行动侧栏并回到海面选点；直升机先保留侧栏选择行/列，完成后再收起。
- 点击遮罩、侧栏标题或按 `Esc` 可关闭侧栏。
- 900px 以下侧栏改为底部抽屉，入口固定在右下方；地图继续保留 42px 触控格和横向滚动。

## 5. 主题与可访问性

- 深海暗夜：原始深蓝海面与青色战术线。
- 极地寒光：提亮海面与浅色控制台，但不使用滤镜处理子元素。
- 黄昏余晖：暖色叠层和金色战术线。
- “减少动画”或系统减少动画时停止海面漂移。
- 高对比度/强制颜色模式移除照片背景，恢复明确单元格边界。
- 坐标按钮的 `aria-label`、键盘聚焦与原确认流程保持。

## 6. 信息安全边界

海面图片只包含无信息水纹；不会按隐藏单位、命中结果或目标类型变化。潜射导弹、核弹、震爆弹的保密反馈不因背景、动画、准线或声音产生侧信道。敌方单位继续不在客户端安全视图中出现。

# Ocean-v1.3.3.2 航母指挥舱 UI

正式对战采用原创航母舰桥内部视角：前方海洋与甲板、下方战术操纵台。原地图、行动面板、战况 / 私人情报 / 系统频道、五类私人标记、右键与手机长按删除、三主题和强调色全部保留。手机使用独立裁切背景，高对比模式隐藏装饰图。本版只完成 2.5D 静态层级与响应式框架，不加入水滴粒子和按钮动态光效。

主题修正版确保 `ocean-dark`、`ocean-light`、`ocean-dusk` 不只改变按键：页面环境渐变、网格纹理、顶栏、底栏、主要面板、航母海景滤色、战术操纵台和地图卡片都会切换为深海蓝、极地浅灰蓝或黄昏棕金。主题切换不修改对局数据。

# Ocean-v1.4.2.2 发布清单

## 版本边界

- 产品版本：`Ocean-v1.4.2.2`
- npm SemVer：`1.4.2-2`
- 规则版本：`rule-v1.8`
- 页面流程：`page-flow-v2.1`
- Socket Protocol：`2.1`
- 基线：`Ocean-v1.4.2.1`

本版只修复桌面对战地图切换条在页面滚动后被回合状态栏遮挡的问题。

## 修复内容

- 901px 以上桌面视口中，地图切换条使用独立粘性位置，固定在回合状态栏下方。
- 切换条层级低于回合栏、高于地图内容，滚动时两者不会互相覆盖。
- 战斗外框从 `overflow: hidden` 改为 `overflow: clip`，保留视觉裁切但不再创建错误的粘性滚动参照。
- 900px 及以下继续使用原手机地图标签与底部行动抽屉规则。

## 未修改内容

- 三套主题与强调色。
- 首屏地图尺寸和行动侧栏高度。
- 诱饵鱼雷分母与雷达起始格文案。
- 游戏规则、数值、AI、教程、音效、信息投影和 Socket 协议。

## 验收要求

- 桌面页面向下滚动后，“己方 / 敌方”地图切换按钮仍完整可见、可点击。
- 回合状态栏、地图切换条和地图内容没有重叠。
- 手机端、三种地图尺寸和三套主题无回归。
- 完整自动化测试、启动与发布包检查通过。

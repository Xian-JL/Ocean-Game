# 《海战 OCEAN》Ocean-v1.2.6 正式发布清单

> 产品版本：Ocean-v1.2.6  
> npm version：1.2.6  
> 稳定代码基线：Ocean-v1.2.4  
> 战斗规则：rule-v1.8  
> 页面流程：page-flow-v2.0  
> Socket Protocol：2.0

## 发布定位

Ocean-v1.2.6 是 v1.2.4 的战术标记与三人规则升级版。它保留 1v1 联机、1v1 人机、三人 FFA、10×10 / 12×12 / 15×15、声音设置、断线重连、终局鱼雷和全部既有战斗数值；不增加数据库、第三方 AI、付费服务或三人人机。

## 本版交付

### 五类私人标记

- 每张敌方地图上方展示“确定有、水面有、水面无、水下有、水下无”五种工具。
- 选择工具后左键未知格直接写入或覆盖；右键当前可见的私人标记格删除。
- 命中、未命中、潜射/核弹标记和侦察区域仍由服务器生成，不可被本机标记修改。
- 标记按房间、本机玩家和敌方玩家隔离保存在浏览器，不进入服务器状态。

### 三人一次同步行动

- 每名玩家每回合只提交一次行动；同一坐标、区域、行或列同步作用另外两名仍在局敌人。
- 两名防守方的命中、伤害、诱饵、瘫痪、探测和雷达分别结算。
- 弹药、使用次数、行动编号和行动方自损只结算一次。
- 驱逐舰同时命中两个单位只自损 0.5；混合命中单位与诱饵时采用一次较高自损 1。
- 海盗船同步命中两方时两方各受 2，海盗船自损 1，己方航母联动只触发一次。
- 首回合雷达同一区域同时扫描两名敌人，并只向行动方返回两份分组结果。
- 一名敌人已出局时自动退化为单目标行动。

### 消息安全

- 三人公共行动记录隐藏两名防守方的具体结果。
- 行动方只收到按敌方玩家分组且规则允许公开的结果，不收到敌方舰种、生命值或伤害。
- 每名防守方只收到自己的受击和状态变化，不收到另一名防守方结果。
- 潜射导弹、核弹和震爆弹继续不向行动方报告命中或生效；核弹命中每名航空母舰各造成 2 点伤害。

### 地图显示比例

- 三人战斗地图按 0.85 显示。
- 所有模式的 15×15 地图再按 0.9 显示。
- 三人 15×15 两项叠加为 `0.85×0.9=0.765`。
- 坐标轴和格子作为同一 `.ocean-board` 整体缩放，服务器坐标与规则参数不变。

## 上线门槛

```text
npm ci
npm run acceptance
```

必须通过语法检查、全部自动测试与验收脚本。专项回归至少覆盖：

- 五类标记选择、覆盖、本地隔离与右键删除，且自动标记不受影响；
- 三人普通攻击、雷达、探测、震爆、潜射导弹、核弹和直升机的同步双防守方结算；
- 同时命中两方、只命中一方、单位/诱饵混合命中的一次行动方代价；
- 两方独立敌方地图与分角色消息不串线；
- 一名敌人出局后的单目标退化；
- 三人 0.85、15×15 0.9、三人 15×15 0.765 的显示规则；
- 1v1 联机与 1v1 人机既有流程完整回归。

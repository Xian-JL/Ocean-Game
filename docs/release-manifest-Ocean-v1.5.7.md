# Ocean-v1.5.7 发布清单

基线：稳定的 Ocean-v1.5.5 代码直接视为 Ocean-v1.5.6。npm：1.5.7。规则：rule-v1.8。页面流程：page-flow-v2.1。Socket：2.1。

## 本版范围

1. 在己方与敌方沙盘上新增3.6秒短时战斗特效层；特效层不接管指针事件，到时自动卸载。
2. 潜射导弹、核弹、震爆弹、探测弹、雷达扫描和直升机扫射分别映射专用过程素材；普通舰艇攻击根据合法可见结果映射爆炸或水花。
3. 命中、未命中、瘫痪、诱饵摧毁和单位沉没使用独立地块与状态反馈。
4. 防守方受击效果只比较前后两份己方安全战场快照，不读取敌方隐藏部署或服务器权威记录。
5. 三人模式下，行动方按 defenderId 在两张敌方安全地图分别显示合法结果；非行动方不能看到另一名防守方的结果特效。
6. 10×10、12×12、15×15均支持区域和整行/整列特效；遵守 `prefers-reduced-motion`。

## 信息保密边界

- 潜射导弹、核弹和震爆弹在行动方视图始终为 `unknown`，仅显示固定的中性过程动画，不显示爆炸/水花差异。
- 探测弹和雷达结果仅使用行动方收到的 `privateResultsByDefender` 或单目标私人结果。
- 普通冲撞和直升机仅使用安全视图中的 `result`、`resultsByDefender`、`cellResults` 或 `cellResultsByDefender`。
- 防守方只能看到自己舰队变化所对应的受击、沉没、瘫痪与诱饵反馈。
- 特效模型不读取 `inflictedDamage`、目标单位类型、实际目标种类或敌方权威舰队。

## 保持不变

- 规则、伤害、生命值、弹药、地图尺寸、人机策略、三人同时结算和最终齐射不变。
- Socket 2.1事件、服务器权威结算和信息投影结构不变。
- v1.5.5行动自动切图、确认倒计时、反馈折叠、行动卡折叠和日志避让完整保留。
- 第一批57项与第二批48项2.5D素材文件未重新压缩或修改。

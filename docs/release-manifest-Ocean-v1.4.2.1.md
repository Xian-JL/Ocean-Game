# Ocean-v1.4.2.1 发布清单

## 版本边界

- 产品版本：`Ocean-v1.4.2.1`
- npm SemVer：`1.4.2-1`
- 规则版本：`rule-v1.8`
- 页面流程：`page-flow-v2.1`
- Socket Protocol：`2.1`
- 基线：`Ocean-v1.4.2`

本版只修复三项已确认问题，不修改极地寒光配色，不修改规则、数值、信息投影、AI、教程、声音资源或联机协议。

## 修复内容

1. 诱饵鱼雷分母
   - 对战行动侧栏、单位状态与赛后复盘均读取安全视图中实际诱饵鱼雷数组长度。
   - 10×10、12×12、15×15 分别显示 `2`、`3`、`5` 为总数。

2. 雷达坐标文案
   - 雷达提示统一为选择扫描区域的“左上起始格”。
   - 震爆弹和探测弹仍按既有规则使用“中心格”。
   - 只修改界面说明，不修改合法坐标、区域计算或结算结果。

3. 战斗首屏与侧栏
   - 桌面对战主容器取消多余入口顶距，压缩装饰层和地图切换区。
   - 方形战区宽度由当前视口高度共同约束，避免首屏被强制撑高。
   - 行动与消息侧栏分别约束外框和内部滚动区，避免越过视口底部。
   - 900px 及以下仍使用原手机底部抽屉与 42px 触控格规则。

## 验收要求

- 10×10、12×12、15×15 对局的诱饵总数分别为 2、3、5。
- 雷达显示“左上起始格”，震爆弹与探测弹显示“中心格”。
- 桌面首屏地图完整可见，打开行动或消息侧栏后底部不越出视口，超长内容在侧栏内部滚动。
- 三套主题外观与 v1.4.2 一致。
- 完整自动化测试、音频素材校验、启动和健康检查通过。

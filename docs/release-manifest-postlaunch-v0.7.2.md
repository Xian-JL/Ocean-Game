# 《海战 OCEAN》postlaunch-v0.7.2 发布清单

> 版本：0.7.2  
> 阶段：postlaunch-v0.7.2  
> 玩法基线：postlaunch-v0.6.2  
> 规则：rule-v1.4  
> Socket Protocol：1.5

## 范围

v0.7.2 只重构正式对战主界面和地图交互表现，不修改服务器游戏逻辑。

## 完成项

- 对战页升级为多地图工作区；
- 三人模式同时渲染己方、敌方 B、敌方 C 三张独立地图；
- 每张地图支持纯 UI 最小化 / 展开，至少保留一张展开；
- B / C 地图继续读取各自 `enemyMapsByPlayer` 独立记录；
- 三人回合显示完成目标数以及每名敌方的已完成 / 待操作状态；
- 第一项行动完成后保持同一玩家、同一 90 秒倒计时，并突出剩余目标；
- 点击敌方地图或目标卡可切换普通单目标行动目标；
- 直升机多目标规则不变，可在两张敌方地图同步预览同一行 / 列；
- 私人标记按敌方玩家分别存储和显示；
- 平板和手机端使用独立地图 Tab；
- 主战场减少常驻解释文字。

## 明确未修改

- 舰船与弹药数值；
- 伤害、范围、合法性；
- 三人双目标回合规则；
- 首次雷达；
- 直升机多目标结算；
- 最终鱼雷多目标结算；
- 90 秒计时；
- 瘫痪、淘汰、胜负；
- 隐藏信息投影；
- 断线重连；
- 服务器权威模型。

## 验收

必须继续通过全部既有逻辑测试，并增加 v0.7.2 多地图 UI 回归测试。

# Ocean-v1.5.3 发布清单

基线：Ocean-v1.5.2。npm：1.5.3。规则：rule-v1.8。页面流程：page-flow-v2.1。Socket：2.1。

## 本次改动

1. 桌面中央沙盘使用满幅矩形容器，取消旧版按高度限制宽度的正方形约束。地图切换、反馈、左右栏与海图间距统一收紧为8px。
2. 10×10、12×12、15×15网格分别按容器宽高适配，坐标、实际占格和点击目标不改变。格子的视觉长宽不强制相等。
3. 取消整板透视缩小，保留海面、舰体、阴影层次。底部112px控制台保留8px安全空间；三人同步提示单独预留28px。
4. 28张舰艇及诱饵方向图使用带3px安全边界的有效图像SVG视口，等比适配占格，避免透明方形画布把舰体缩成细小图标。原57项美术文件保持不变。
5. 航母继续逐格连接，潜层、受损、瘫痪、沉没、选中状态和私人信息隔离保持。无新依赖，不需要服务器数据迁移。
6. 仅普通桌面对战启用满幅布局；900px及以下移动端和最终齐射保留原布局。舰体显示改进共用于部署、己方对战和公开复盘。

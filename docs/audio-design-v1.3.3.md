# 《海战 OCEAN》音效设计 v1.3.3

> 对应产品：Ocean-v1.3.3  
> 音效库版本：3.0

## 范围

v1.3.3 只更新音效资源与浏览器播放层，不修改 rule-v1.8、page-flow-v2.1、Socket 2.1、五章教程、三档人机、三人行动、私人标记、主题或强调色。

## 真实素材层

- 驱逐舰：K-55 炮击；两型驱逐舰使用相同来源，通过播放速率区分重量。
- 潜射导弹：水下压力、真实导弹点火、破水水花固定叠加。
- 摩托艇：快艇循环、发动机、金属冲撞与水花。
- 核弹：固定警报与发射声。
- 震爆弹：固定充能、电击与短促冲击。
- 探测、雷达：分别使用声呐 Ping、扫描与潜艇声呐回波。
- 直升机：真实旋翼片段。
- 部署、私人标记、房间、教程和通用界面使用 Kenney 与已筛选短音效。

所有声音均从 `/public/assets/audio/effects/source/` 本地读取，不依赖运行时外部网站。

## 信息安全

潜射导弹、核弹、震爆弹始终只根据行动类型播放固定组合，不读取命中、伤害、目标类型或私人结果。普通命中也只播放通用舰体受击声，不通过音色区分敌方单位。

## 播放与回退

浏览器使用 `fetch + decodeAudioData + AudioBufferSourceNode` 解码和播放真实素材，继续经过效果母线、动态压缩器和音量控制。文件缺失、请求失败或格式无法解码时，自动回退到 v1.3.2 的合成音效，避免操作完全静音。

## 兼容约束

- `EFFECT_LIBRARY_VERSION = "3.0"`。
- 效果与背景音乐继续独立开关、独立音量。
- 最大并发效果数继续为 12。
- `ocean-theme.mp3` 仍为可选背景音乐。
- 移动端第一次用户交互后允许浏览器激活 AudioContext。

# 《海战 OCEAN》postlaunch-v0.7.4 发布清单

> 版本：0.7.4  
> 阶段：postlaunch-v0.7.4  
> 玩法基线：postlaunch-v0.6.2 / rule-v1.4  
> Socket Protocol：1.5

## 范围

v0.7.4 只重构正式对战中的战场动态、行动反馈、单位/玩家状态提示与断线重连表现，不修改服务器游戏逻辑。

## UI 变更

1. 战场动态分为“战况 / 私人情报 / 系统”三个频道。
2. 战况按行动方 → 目标玩家 → 行动 → 公开结果组织，三人局目标关系更清晰。
3. 私人情报只读取当前玩家安全视图中的 `intelligenceAreas` 和本机私人标记。
4. 最近结算区分命中、未命中、结果未知、私人情报和普通结算。
5. 潜射导弹、核弹、震爆等隐藏结果动作不使用命中/未命中视觉提示。
6. 战场玩家状态明确区分在线、行动中、离线、已淘汰。
7. 断线暂停、自动重连和恢复界面改为简洁连接状态卡。
8. Toast 使用统一图标、标题和消息结构，继续保持非阻断。

## 游戏逻辑边界

`server/` 不应因本版 UI 改造发生玩法逻辑变化。三人双目标回合、B/C 独立地图、90 秒共享计时、首次雷达、直升机双目标、最终鱼雷多目标、伤害、瘫痪、淘汰、隐藏信息和断线裁决均保持 v0.6.2。

## 验收

必须继续通过 v0.6.2 玩法逻辑测试与 v0.7.0～v0.7.3 UI 回归，并增加 v0.7.4 战场动态、语义反馈、玩家状态和连接 UI 回归测试。

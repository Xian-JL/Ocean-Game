# 《海战 OCEAN》postlaunch-v0.7.5 发布清单

> 版本：0.7.5  
> 阶段：postlaunch-v0.7.5  
> 玩法基线：postlaunch-v0.6.2 / rule-v1.4  
> Socket Protocol：1.5

## 范围

v0.7.5 完成 v0.7.x UI 系列收尾：最终齐射、结算、再来一局、本地 SVG 美术资源、响应式与可访问性。服务器玩法逻辑保持 v0.6.2。

## UI 变更

1. `FINAL_SALVO` 使用独立终局阶段卡，不再与普通行动面板混排。
2. 玩家只能看到自己的鱼雷选择；其他玩家只显示“已就绪 / 等待选择”，不显示秘密坐标。
3. 终局明确提示同一鱼雷坐标同时作用于其他所有仍在局玩家，不允许 UI 为不同敌人分别选择鱼雷。
4. 结算页重构为结果 Hero、玩家终局状态、再来一局、部署复盘、行动复盘五层结构。
5. 再来一局逐玩家显示申请状态，并保留申请 / 取消 / 离开房间操作。
6. 新增 `public/assets/icons/ocean-ui.svg` 本地 SVG sprite，覆盖 7 类舰船、诱饵、10 项行动和主要结果/状态图标。
7. 舰队状态、行动卡、首次雷达、Toast、最终齐射和结算页开始统一使用本地 SVG。
8. 增强窄屏、触控、高对比度与键盘焦点表现；继续支持 `prefers-reduced-motion`。

## 游戏逻辑边界

本版不修改三人双目标回合、B/C 独立敌方地图、90 秒共享计时、首次雷达、直升机多目标、最终鱼雷多目标、舰船数值、伤害、瘫痪、淘汰、胜负、断线恢复和隐藏信息边界。

## 验收

必须继续通过 v0.6.2 玩法逻辑测试、v0.7.0～v0.7.4 UI 回归，并增加 v0.7.5 最终齐射、结算、再来一局、本地 SVG 与响应式回归测试。

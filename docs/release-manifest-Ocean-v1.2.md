# 《海战 OCEAN》Ocean-v1.2 正式发布清单

> 产品版本：Ocean-v1.2  
> npm version：1.2.0  
> 稳定代码基线：Ocean-v1.1  
> 战斗规则：rule-v1.6  
> 页面流程：page-flow-v1.7  
> Socket Protocol：1.8

## 发布定位

Ocean-v1.2 保留 1v1 联机、1v1 人机和三人 FFA 的完整规则，新增服务器权威的三档动态地图，并改善声音与即时播报体验。仍采用单体 Node.js + Socket.IO 架构，不增加数据库、外部 AI 或付费服务。

## v1.2 新增能力

- 房主可选 10×10、12×12 或 15×15，默认 12×12。
- 航空母舰占格/生命值、诱饵鱼雷数量、两艘驱逐舰攻击范围、雷达与震爆范围按同一确定性算法派生。
- 坐标、部署验证、随机部署、人机决策、目标验证、战斗状态和安全视图全部读取房间 `mapRules`。
- 12×12 数值保持 v1.1 不变；10×10 与 15×15 使用 rule-v1.6 中冻结的档位表。
- 增加本地 Web Audio 合成音效，无需额外音效素材或联网加载。
- 预留可循环背景音乐；用户提供的文件放到 `public/assets/audio/music/ocean-theme.mp3`。
- 音效与背景音乐分别开关，偏好保存在当前浏览器；音乐缺失不阻断游戏。
- 右侧实时播报缩小为右上角轻量卡片，支持点击卡片、关闭按钮或键盘立即关闭。
- 底部“战况 / 私人情报 / 系统”三频道的内容、历史与信息隔离保持 v1.1 逻辑。

## 上线门槛

```text
npm ci
npm run acceptance
```

必须通过全部既有回归测试与 v1.2 动态地图、音效和实时播报专项测试，且三种地图都能完成创建、部署、首回合雷达、正常行动、结算和再来一局。

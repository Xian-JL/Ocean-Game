# Ocean-v1.5.8 发布清单

基线：Ocean-v1.5.7。npm：1.5.8。规则：rule-v1.8。页面流程：page-flow-v2.1。Socket：2.1。

## 本版范围

1. 三人模式顶部回合提示、行动面板和确认框统一说明：一次行动使用同一坐标或范围同步作用于两名存活敌方，弹药、行动次数和行动方自损仅结算一次。
2. 两张敌方地图继续共用一块中央大沙盘；切换标签不会清空同步行动的目标和范围预览。
3. 敌方标签新增在线、离线、淘汰、最新行动受影响、目标坐标、权限内结果和未读结果状态。
4. 最新反馈将行动与坐标只显示一次，并按防守方列出独立结果；雷达与探测结果仅对行动方显示，隐藏结果行动继续显示未知。
5. 战斗日志中的三人同步攻击保持一条行动记录，展开后按当前查看权限显示各方结算，不暗示重复消耗。
6. 淘汰玩家地图、公开结果和本机历史标记继续保留，但不允许再选择行动或修改标记；选择新行动时自动聚焦存活敌方，同步状态自动变为单目标。
7. 三人2.5D短时特效只在结算到达时正在查看的地图播放；其他地图显示未读徽标和静态最新结果地块，切换后不重播动画。
8. 断线遮罩明确显示离线玩家、行动倒计时已冻结、冻结时剩余时间和重连后的恢复方式。

## 信息保密边界

- 行动方仅使用服务器安全视图中的 `resultsByDefender`、`cellResultsByDefender` 和 `privateResultsByDefender` 生成逐方结果。
- 潜射导弹、核弹和震爆弹对行动方继续统一显示“结果未知”，不根据敌方伤害或舰体变化推断命中。
- 防守方逐方反馈只生成自己的结果行；另一名防守方的结果既不读取也不显示。
- 历史公开日志不具备逐方结果时只显示“按权限展示”，不从服务器权威行动记录补充客户端不应获得的信息。
- 2.5D效果层继续不读取敌方真实部署、单位类型或未公开伤害事件。

## 保持不变

- rule-v1.8 的伤害、生命值、弹药、行动次数、首回合雷达、最终齐射和三人同时结算不变。
- Socket 2.1事件、服务器权威结算、信息投影结构、AI策略和地图规则不变。
- 10×10、12×12、15×15地图、桌面大沙盘、移动端单地图切换和减少动态效果设置不变。
- 第一批57项与第二批48项2.5D美术资源未新增、替换或重新压缩。

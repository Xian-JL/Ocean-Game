# Ocean-v1.5 发布清单

## 版本边界

- 产品版本：`Ocean-v1.5`
- npm SemVer：`1.5.0`
- 规则版本：`rule-v1.8`
- 页面流程：`page-flow-v2.1`
- Socket Protocol：`2.1`
- 代码基线：`Ocean-v1.4.2.2`

本版仅重构正式战斗页的桌面表现层和本地战术视层，不修改服务器权威规则、数值、信息投影、AI、教程、音效或联机协议。

## 概念图落地

1. 顶部舰桥状态条
   - 显示房间号、回合、当前行动状态、倒计时、玩家在线状态和连续超时。
   - 桌面对战隐藏通用网站导航，避免出现两套顶栏。

2. 中央立体沙盘
   - 复用舰桥海景与战术海面素材。
   - 地图使用轻度透视、发光网格和 SVG 舰种轮廓，同时保持原坐标按钮与服务器目标数据。
   - 敌我地图继续通过顶部标签互斥切换；三人局保留两张独立敌图。

3. 左右战术控制台
   - 左侧固定战斗日志、情报信息和系统消息入口。
   - 右侧常驻坐标读数、首次雷达、舰队生命值、弹药和十项行动。

4. 底部连续控制台
   - 综合、水面、潜层三档只影响己方沙盘视觉强调。
   - 五种私人标记继续只保存在本机。
   - 目标确认调用既有确认弹窗；取消、说明和投降继续调用原事件。

## 保持项

- 10×10、12×12、15×15 动态规则及舰队数量。
- 1v1 联机、1v1 人机和 3 人 FFA。
- 首回合雷达、最终鱼雷齐射、重连、再来一局和赛后复盘。
- 深海暗夜、极地寒光、黄昏余晖及五种强调色。
- 900px 及以下手机端 42px 触控格、横向滑动和底部抽屉。
- 减少动画、高对比度和键盘焦点能力。

## v1.5.1 预留

- 替换更精细的舰船俯视图、武器缩略图、舰桥侧框和控制台纹理。
- 只允许替换美术资产与对应尺寸适配，不改变 v1.5 已冻结的布局结构和交互入口。

## 验收要求

- 桌面 1366×768、1600×900、1920×1080 下核心控制台不越界，地图和确认按钮可操作。
- 三种地图、三种主题、双人/三人、人机、首次雷达和普通行动均可完成。
- 手机端不启用透视沙盘和桌面底部控制台。
- 完整自动化测试、启动、音效资源和发布一致性检查通过。

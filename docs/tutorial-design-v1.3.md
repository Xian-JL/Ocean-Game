# 《海战 OCEAN》完整交互教程设计 v1.3

> 对应产品：Ocean-v1.3  
> 规则依据：rule-v1.8  
> 教程数据版本：1.0  
> 运行方式：浏览器本地、无房间、无 Socket 写操作

## 1. 教程目标与边界

教程的目标不是复刻一整局，而是在十分钟左右让新玩家掌握进入真实对局所需的五个核心能力：合法部署、正确选择行动、理解单格只结算一次伤害、使用情报与私人标记、理解信息保密和特殊规则。

教程遵守以下边界：

- 不创建房间，不占用服务器席位，不修改服务器对局状态；网络断开时仍可使用。
- 使用独立的确定性模拟数据，所有命中位置和生命值变化都是教学脚本，不冒充真人对局。
- 不降低真实对局规则。教程展示的伤害、范围、保密信息和特殊结算必须与 rule-v1.8 一致。
- 错误点击只提供纠正信息，不扣除真实资源，不自动越过尚未完成的步骤。
- 完成状态只是“已完成章节”列表，不是胜率、账号或云端存档。

## 2. 入口、退出与进度

- P01 首页创建区提供“完整交互教程”；O01 游戏说明的人机章节提供同一入口。
- 进入后显示本地训练标识，不显示房间码，不进入 P02～P06。
- 首次进入从第一章开始；再次进入自动定位到第一章未完成内容；全部完成后默认打开第一章供复习。
- 玩家可打开已经完成的章节，也可提前查看其他章节；章节内的完成判定仍必须由对应操作触发。
- 退出教程返回 P01，并恢复玩家在首页选择的地图大小。
- 教程完成页提供“选择新手人机”，返回 P01 后预选 1v1 人机、新手、12×12，但不自动创建房间。
- `localStorage` 键为 `ocean.tutorial-progress.v1`，只保存教程数据版本和合法章节 ID。损坏、版本不符或不可写时安全回退，不影响游戏。

## 4. 章节细节

### 4.1 第一章：秘密部署

1. 初始只激活驱逐舰Ⅰ工具和 B2 引导格。
2. 点击 B2 后模拟水平占据 B2、B3、B4，提示部署预览成立。
3. 点击“旋转”后模拟占据 B2、C2、D2并完成本章。
4. 概念卡同时解释：线形单位只能水平或垂直连续；潜水艇和核潜艇必须为完整 2×2；航空母舰六格必须全部四向连通；不同对象可相邻但不得重叠或越界。

### 4.2 第二章：攻击与受击格

1. 驱逐舰Ⅰ第一次攻击 D6：目标生命值 3→2，己方驱逐舰 3→2.5，D6 标为已结算命中格。
2. 再次用驱逐舰攻击 D6：操作被拒绝，解释驱逐舰每个坐标只可尝试一次。
3. 切换核弹再攻击 D6：攻击方只得到“核弹已投放，命中情况保密”；由于 D6 已经受过伤害，目标生命值保持 2。
4. 本章明确区分“允许再次选为单格目标”和“同一单位占格不会再次扣血”。潜射导弹标记不等于受击结算，因此不能据此跳过后续范围攻击。

### 4.3 第三章：情报与私人标记

1. 12×12 教学图以 C3 作为雷达 4×4 的左上角，显示 16 格扫描覆盖。
2. 雷达只回答范围内是否存在任何敌方布局，不公开数量、层级、单位名称或具体坐标。
3. 玩家选择“水下有”并点击 E5，生成本机私人标记；它可以被覆盖或删除，不会同步给服务器。
4. 选择探测弹并点击 H8，显示完整 3×3 范围；探测只回答范围内是否存在存活水下单位未受击格或有效诱饵信号。
5. 概念卡列出五种私人标记：确定有布局、水面有、水面无、水下有、水下无；自动命中/未命中标记不受私人标记覆盖。

### 4.4 第四章：隐藏武器与分角色播报

1. 潜射导弹攻击 G7：攻击方只见“导弹已发射，结果未知”；防守方看到自己的潜水艇生命值 2→1。
2. 核弹攻击 H8：攻击方只见“核弹已投放，命中情况保密”；防守方看到航空母舰生命值 6→4。
3. 震爆弹以 F6 为中心形成完整 5×5：攻击方不知道是否瘫痪；只有命中的存活水下作战单位可能在其下个正常回合瘫痪，水面单位和诱饵鱼雷不受影响。
4. 明确所有公开实时播报与底部记录均不得突破角色信息边界。

### 4.5 第五章：最终指挥考核

四题必须覆盖：

1. 海盗船只要受到伤害，己方航空母舰联动扣 0.5；海盗船成功命中时自身再承受规则规定的自损。
2. 摩托艇命中水下作战单位时视为未命中；撞到诱饵会沉没，只有命中航空母舰才对目标造成 1 点伤害。
3. 三人局一次行动同时作用两名敌人，但弹药和行动方自损只结算一次；每名防守方独立受影响。
4. 所有攻击手段耗尽后进入终局鱼雷，玩家逐轮秘密选择未引爆诱饵，全部应提交方完成后同时结算。

答错时保留当前题并解释原因；答对后进入下一题。全部答对后才写入第五章完成记录。

## 5. 交互、可访问性与手机端

- 所有教学操作使用原生按钮语义、键盘焦点和 `aria-live` 状态提示；颜色之外同时提供文字、图形或边框。
- 引导格具有明显轮廓，但不阻止玩家点击其他格；错误格会返回具体目标坐标。
- 进度条只使用外部 CSS 的离散 20% 档位，满足正式 CSP 禁止内联样式的要求。
- 手机端地图格保持 42px，可横向滚动；章节标签和工具条横向滚动；底部上一章/下一章操作遵守安全区。
- 减少动画偏好继续生效；教程动画只表达状态，不延迟成功判定。

## 6. 验收标准

- 五章可从零进度连续完成，完成百分比为 100%。
- 错误操作不推进步骤；重复进入能恢复合法章节进度；非法本地数据会被忽略。
- 教程期间没有 `room:create`、`room:join` 或 `action:submit`。
- 退出后首页状态、正式地图尺寸和所有真实房间功能正常。
- 320px 手机宽度至桌面布局均能完成所有必需点击。
- 教程所述伤害、范围和消息保密与 rule-v1.8 自动测试一致。

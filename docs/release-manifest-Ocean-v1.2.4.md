> 产品版本：Ocean-v1.2.4  
> npm version：1.2.4  
> 稳定代码基线：Ocean-v1.2.1

> 页面流程：page-flow-v1.9  
> Socket Protocol：1.9

## 发布定位

Ocean-v1.2.4 是 v1.2.1 的联机显示与信息安全修订版。它保留 1v1 联机、1v1 人机、三人 FFA、三档动态地图、独立音量和地图下方三频道，集中处理地图坐标、声音入口、核弹回归验证与分角色战报。架构仍为单体 Node.js + Socket.IO，不增加数据库、外部 AI 或付费服务。

## v1.2.4 修订内容

### 地图坐标

- 所有地图的左上角、数字列号、字母行号和海域格均写入明确的 CSS Grid 行列位置。
- 部署地图、1v1 双地图与三人 FFA 三张地图共用同一坐标渲染器。
- 10×10、12×12、15×15 均按服务器下发的 `mapRules` 生成，不依赖 DOM 自动排列。

### 声音设置

- 顶部“音效”和“背景音乐”按钮均打开独立声音设置层，并分别聚焦相应音量滑杆。
- “帮助 / 游戏说明”不再容纳声音开关和滑杆。
- 两类声音仍可独立开关、独立调节 0～100 音量并在本地浏览器持久化。

### 行动信息边界

- 普通单格攻击的行动方只获得“命中”或“未命中”；直升机行动方只获得逐格命中/未命中结果。
- 行动方不再收到敌方 `inflictedDamage`，不得获知敌方单位类型、单位名称、实际伤害、剩余生命值或沉没状态。
- 防守方专属 `receivedHits` 包含己方单位、结算前生命值、实际伤害、结算后生命值和沉没状态。
- 行动方自己的自损与己方联动伤害仍完整可见；第三方继续只获得公开信息。
- 潜射导弹、核弹和震爆弹不向行动方报告是否命中或生效。

### 核弹伤害回归

- 核弹命中航空母舰时固定造成 2 点伤害。
- 核弹命中其他可攻击单位时造成 1 点伤害。
- 自动测试同时验证服务器伤害值、防守方生命值变化，以及行动方无法取得核弹命中信息。

## 上线门槛

```text
npm ci
npm run acceptance
```

必须通过语法检查、全部自动测试与验收脚本。专项回归至少覆盖：

- 1v1 和三人模式的所有地图坐标对齐；
- 两个顶部声音入口、独立面板、开关、滑杆与本地持久化；
- 核弹对航空母舰造成 2 点伤害；
- 普通攻击的行动方/防守方/第三方信息隔离；
- 潜射导弹、核弹和震爆弹的隐藏结果。

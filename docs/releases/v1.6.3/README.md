# Ocean v1.6.3 发布记录

## 发布范围

2026-10-24，将当前完整工作区以 v1.6.3 发布。包含 UI SPEC 2.0“黑潮军械库”、核心战斗训练营收敛、原特效保留与强化，以及已完成的依赖安全更新。产品版本1.6.3，UI规范2.0，规则1.8，Socket2.1。

电影感舰坞首页、原创舰徽/字标/武器刻印、中央海图与固定十槽军械台，以及整备、掷骰、训练、结算/复盘、覆盖层的统一视觉随本版交付。支持炉火/冷铸/铸白三主题、本机战徽、字号与密度，以及手机抽屉和低高度侧置指令台。

训练营为四步快速上手、十种武器试射和不计时的自由练习，预部署并由陪练自动回应。开发目录、角色切换与虚拟时钟不再是玩家入口。原有规则、安全投影、正式会话和训练隔离保持。

## 验证与验收边界

发布版本的完整基础验收见 acceptance.log，资源及冻结文件指纹见 build-manifest.json，依赖审计见 dependency-audit.json。仅迁移当前产品版本断言，不改历史规则或旧发布证据。

UI SPEC 2.0 的开发证据仍保留在 docs/ui-v2，其中截图和日志标明原始构建，不把产品改版号当作重新采集。真机、完整视觉矩阵、正式LCP/帧率/内存与用户最终审美仍待独立验收。发布不表示这些未测项已经通过。

发布基础验收实际结果：738项通过、0失败、0跳过；53组音效与语法检查通过，npm audit为0。24个正式规则/Socket/安全视图文件与UI2开发起点指纹一致。新增打包脚本没有改变业务代码。

发布前检查发现一份历史文件在Windows工作区与Git中使用不同换行。新增冻结检查改为统一LF后比对24个已验证内容指纹，原始字节指纹仍保留；只允许CRLF/LF差异，不放松规则、协议或安全投影内容检查。原始失败日志保留其输出空白，不作为源码格式错误修剪。

精简运行包已解压到独立目录，只执行npm ci --omit=dev安装89个生产依赖，并重新构建得到相同资源指纹。健康版本、首页版本替换、JS/CSS/Socket客户端/图标/双端美术、四步与十武器课程、凭证隔离和开发接口关闭均通过；还通过真实HTTP提交完成一次核心战斗课程。详情见runtime-smoke.json。

## 下载与运行

GitHub标签提供完整源码自动归档，Release另提供精简运行包、证据包和SHA256SUMS.txt。运行包使用 npm ci --omit=dev，然后 npm start；需Node.js24及以上。Windows可使用start.cmd。源码包开发安装 npm ci，修改client后 npm run build。

运行包只包含运行、构建与必要说明，不包含node_modules、Git目录、原图和开发截图。原始美术、提示、验收资料与源码保留于仓库及证据包。正式房间仍为内存状态，服务重启会中断进行中的房间。

# Ocean v1.6.4 · 战斗前端精修

## 范围与冻结

本版只处理前端HUD、海图操作、移动端与低高度、十行动表现、己方舰艇表现和可访问性。全部server文件、客户端规则/安全模型/音频实现、训练课程与界面、教程及结算复盘视图均保持原内容；共用战斗组件的展示修正会同步作用于使用该组件的既有练习，但没有新增训练功能。42份源文件的冻结指纹见frozen-scope.json，自动测试逐文件核对。

产品1.6.4，规则1.8，Socket2.1。没有新增后端接口、隐藏信息广播、伤害公式、资源、解锁或行动时机。所有选择与确认继续走既有命令链。

## 实现

| 方向 | 实际变化 |
| --- | --- |
| HUD | 十槽固定顺序与完整可读名称；来源舰与实际HP；短风险常驻，完整原规则说明可触摸/键盘打开；确认区固定 |
| 海图 | 吸附坐标轴、纯几何视窗概览、坐标定位、回到目标、按身份保存定位草稿、放大保持视窗锚点 |
| 移动端 | 40/48px格、低高度侧台、安全区和大字武器抽屉；扫射方向选完返回海图；详情保留完整风险 |
| 十行动 | 单/双脊冲撞、钩刃、V尾迹、密封弹体、裂核压力环、分段EMP、双声呐、扫描刃与行/列扫射；保留旧位图 |
| 舰艇 | 实际来源肖像放大；航母按自己真实模块关系绘制横向肖像；克制尾迹/阴影，舰体与状态保持清楚 |
| 可访问性 | 1～0只选择武器，输入框/弹窗不截键；定位Enter不发射；失图文字回退；强制颜色保留舰体文字；旧观察器/监听释放 |
| 加载 | 不再在高画质一次预载全部未选武器插画；保留共用冲击资源与选中资源预热；不新增库或字体 |

定位和概览仅处理坐标及视窗，不显示隐藏对象；没有自动瞄准或代替用户确认。命中、伤害、未知结果、来源HP仍使用原安全视图。减少动画、后台、换图与resize取消装饰，坐标和事实不随动画位移。

需要Node.js24及以上。源码安装npm ci后npm start；精简运行包安装npm ci --omit=dev后npm start。Release提供runtime ZIP、evidence ZIP及SHA256SUMS.txt，完整源码由标签归档提供。原图和旧验收保留历史意义，不覆盖旧发布。

# Ocean-v1.4.1 发布清单

- 产品：Ocean-v1.4.1
- npm：1.4.1
- 规则：rule-v1.8（实现纠错，版本不变）
- 页面流程：page-flow-v2.1
- Socket：2.1
- UI：完整继承 v1.4 真实海面与沉浸式侧栏

## 本版修复

- 终局攻击能力检查带入实际敌方玩家 ID，与回合合法行动检查保持一致。
- 存活驱逐舰的规则射程全部使用后，正确判定该驱逐舰已无合法攻击目标。
- 所有仍在局玩家均无其他攻击手段时，立即进入 `FINAL_SALVO`，不再循环自动待命。
- 覆盖一方射程耗尽、双方射程耗尽以及三人局仍在局目标变化后的判定。

## 明确未修改

- 驱逐舰Ⅰ、驱逐舰Ⅱ的范围、共享坐标限制、伤害和自身损伤。
- 其他单位、弹药、辅助行动、最终鱼雷和胜负数值。
- UI、三档人机、教程、房间、重连、复盘和私人标记。
- Socket 2.1 事件结构与隐藏信息投影。

## 验收重点

- 驱逐舰存活且仍有未使用射程格时，不能提前进入终局。
- 仅一方因射程耗尽失去最后攻击手段，另一方也无攻击手段时进入终局。
- 双方驱逐舰均存活且射程均耗尽时进入终局。
- 临时瘫痪仍只触发自动跳过，不能被误判为永久耗尽。

# 《海战 OCEAN》游戏规则 v1.6

> 文档状态：Ocean-v1.2 正式规则  
> 编制日期：2026-08-07  
> 修订日期：2026-08-19  
> 规则依据：经用户确认的完整游戏规则、最新版规则附件及原 Ocean.cpp 撰写者的追加说明。

## 1. 首版产品范围

《海战 OCEAN》是一款浏览器回合制策略游戏，支持双人联机、1v1 人机和三人自由对战。玩家秘密部署舰队，并轮流在敌方地图上执行舰艇行动。服务器保存所有玩家完整状态并负责合法性验证、伤害计算、信息隐藏和胜负结算。

首版包含：

- 双人或三人房间码对战，以及独立的 1v1 人机对战；
- 游客昵称，无账号系统；
- 手动部署和随机部署；
- 舰艇行动、特殊武器、探测、断线重连、投降、行动超时、复盘和再来一局；
- 桌面端和手机浏览器基本适配。

首版不包含：

- 排位、排行榜、好友、聊天和观战；
- 商城、付费内容和广告；
- 三人人机、机器人互战和四人及以上对战；
- 舰艇移动和账号战绩系统。

## 2. 统一术语

下列术语在规则、界面、程序变量和测试中含义固定，不使用同义词替换。

| 术语 | 唯一定义 |
| --- | --- |
| 玩家 | 对局中的一方。每局由房主固定选择两名或三名玩家。 |
| 地图 | 每名玩家各有一张本房间选定尺寸的正方形海域；所有玩家地图使用相同坐标系。 |
| 格 | 地图中的一个坐标位置。 |
| 作战单位 | 具有生命值的部署对象；因摩托艇有两艘，每方共八个作战单位。 |
| 水面单位 | 驱逐舰Ⅰ、驱逐舰Ⅱ、海盗船、摩托艇和航空母舰。 |
| 水下单位 | 潜水艇和核潜艇。 |
| 部署物 | 没有生命值且不属于作战单位的对象；首版仅指诱饵鱼雷。 |
| 单位格 | 某个作战单位占据的格。 |
| 生命值 | 作战单位可承受的剩余伤害，缩写为 HP；最小变化单位为 0.5。 |
| 存活 | 作战单位的生命值大于 0。 |
| 沉没 | 作战单位的生命值小于或等于 0。 |
| 瘫痪 | 存活水下单位受震爆弹影响而暂时不能作为行动来源；瘫痪不造成伤害，也不改变存活或沉没状态。 |
| 回合 | 一名玩家连续完成本轮规定操作的过程。双人局通常包含一次操作；三人局通常需要对每名仍在局敌方玩家各完成一次操作。 |
| 行动 | 玩家在自己的回合中提交并由服务器结算的一次操作。三人局的同一回合可以包含两次分别面向不同敌人的行动；直升机扫射是同时面向全部敌人的例外。 |
| 攻击行动 | 能够直接降低敌方作战单位生命值的行动。 |
| 辅助行动 | 不直接造成伤害的行动；首版指震爆弹和探测弹。 |
| 行动来源 | 发动该行动的己方作战单位。 |
| 目标格 | 玩家主动选择的一个敌方地图坐标。 |
| 攻击范围 | 某行动允许选择目标格的坐标集合。 |
| 作用区域 | 一次行动实际检查或结算的全部格。 |
| 已结算格 | 攻击方已经获得“命中”或“未命中”结论的格。 |
| 潜射标记 | 潜射导弹发射后在目标格留下的“导弹已发射”公开标记；不表示命中或未命中，也不使该格成为已结算格。 |
| 命中 | 攻击依照具体行动规则触及一个可被该行动命中的存活作战单位，或成功摧毁一个诱饵鱼雷；命中不必然造成伤害。 |
| 未命中 | 攻击未触及可被该行动攻击的存活作战单位或诱饵鱼雷。 |
| 伤害 | 从作战单位当前生命值中扣除的数值。 |
| 残骸 | 沉没单位在防守方己方地图上的显示状态，不再属于存活作战单位。 |
| 弹药 | 使用一次即减少一次的有限行动资源。 |
| 私人标记 | 玩家在敌方地图上添加的个人推理标记，对战局无影响且对手不可见。 |

除表中正式名称外，规则不再使用“血量”“滴血”“兵种”“普通炮击”“侦察弹”等近义表述。

“海上单位”和“海下单位”不是正式术语，分别统一写作“水面单位”和“水下单位”。诱饵鱼雷属于水下部署物，不属于水下单位。

## 3. 对局目标与胜负优先级

航空母舰是舰队指挥核心。双人局中，敌方航空母舰生命值降至 0 后，攻击方立即获胜。三人局中，航空母舰沉没者出局，最后一名航空母舰仍存活的玩家获胜。

胜负按下列优先级判定：

1. 攻击行动使目标玩家航空母舰沉没：双人局立即结束，三人局令目标玩家出局；
2. 玩家主动投降：该玩家在双人局落败，在三人局出局；
3. 玩家连续三个实际行动回合超时：该玩家在双人局落败，在三人局出局；
4. 玩家断线超过 120 秒：该玩家按同样规则落败或出局；
5. 所有仍在局玩家均无攻击手段时，进入终局手动鱼雷引爆并比较航空母舰剩余生命值。

海盗船攻击具有唯一的普通对局特例：若海盗船命中所选防守方航空母舰，且该次行动使行动方与防守方航空母舰同时沉没，则海盗船行动方在二人局获胜；三人局按结算后的未出局玩家集合继续判定。若该次行动只使行动方航空母舰沉没而防守方航空母舰仍存活，则海盗船行动方落败或出局。

摧毁全部非航空母舰单位不能直接获胜。

## 4. 房间、准备与先手

1. 玩家昵称长度为 1～12 个字符。
2. 创建房间时，房主选择双人或三人对战以及 10×10、12×12 或 15×15 地图；服务器生成 6 位房间码，其他玩家凭码加入。
3. 房间达到所选人数后才进入准备阶段；未坐满时不启动部署倒计时。
4. 房间坐满后开始 180 秒部署倒计时。
5. 玩家点击“准备”后仍可取消准备，但仅限其他玩家均尚未准备时。
6. 房间内所有玩家同时处于已准备状态后，部署立即锁定，不能再取消准备。
7. 180 秒结束时，服务器为尚未准备的玩家随机补全合法部署并自动准备。
8. 部署锁定后，服务器为每名玩家生成一个 1～6 的骰子结果；唯一最高点获得第一回合，最高点并列时全员重掷。
9. 骰子结果由服务器生成，动画只负责展示，不参与随机计算。

## 5. 地图、坐标与动态规则档位

- 房主创建房间时必须选择 10×10、12×12 或 15×15；房间创建后至本局及再来一局结束均不能改变尺寸。
- 行坐标分别为 A～J、A～L、A～O，列坐标分别为 1～10、1～12、1～15，例如 `B3`。
- 服务器只保存 `mapSize`，所有相关参数均由本节同一确定性算法派生；客户端提交的自定义参数不被信任。
- 设地图边长为 `N`，缩放因子为 `s=N/12`。`nearestOdd(x)`、`nearestEven(x)` 分别表示取不大于 N 的最近奇数或偶数，距离相同时取较小者。
- 航空母舰占格数与初始生命值均为 `round(N/2)`；诱饵鱼雷数量为 `round(3×s²)`。
- 驱逐舰Ⅰ沿舰身/垂直舰身范围为 `nearestOdd(11×s)` / `nearestOdd(7×s)`；驱逐舰Ⅱ为 `nearestEven(10×s)` / `nearestEven(8×s)`。
- 雷达边长为 `round(N/3)`；震爆弹边长为 `nearestOdd(5×s)`；探测弹边长为 `nearestOdd(3×s)`。
- 直升机整行/整列、全图单格目标和坐标边界直接使用 N；其余舰艇占格、生命值、弹药和伤害不随地图改变。

| 地图 | 航空母舰占格/HP | 诱饵鱼雷 | 驱逐舰Ⅰ 沿×垂直 | 驱逐舰Ⅱ 沿×垂直 | 雷达 | 震爆弹 | 探测弹 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 10×10 | 5 / 5 | 2 | 9×5 | 8×6 | 3×3 | 5×5 | 3×3 |
| 12×12 | 6 / 6 | 3 | 11×7 | 10×8 | 4×4 | 5×5 | 3×3 |
| 15×15 | 8 / 8 | 5 | 13×9 | 12×10 | 5×5 | 7×7 | 3×3 |

- 所有玩家的舰艇在部署锁定后不再移动。
- 每名玩家拥有两种地图视图：
  - 己方地图：显示己方全部部署、生命值、弹药、受击格和残骸；
  - 敌方地图：只显示该玩家通过行动获得的公开信息和私人标记；三人局对每名敌方玩家分别维护独立敌方地图，不混合命中、未命中、隐藏武器标记、侦察区域或私人标记。

## 6. 舰队配置

| 正式名称 | 类别 | 数量 | 占地形状 | 初始生命值 | 行动或资源 |
| --- | --- | ---: | --- | ---: | --- |
| 驱逐舰Ⅰ | 水面单位 | 1 | 1×3 直线 | 3 | 驱逐舰Ⅰ冲撞；范围按地图档位取 9×5、11×7 或 13×9 |
| 驱逐舰Ⅱ | 水面单位 | 1 | 1×4 直线 | 3 | 驱逐舰Ⅱ冲撞；范围按地图档位取 8×6、10×8 或 12×10 |
| 潜水艇 | 水下单位 | 1 | 2×2 方形 | 2 | 潜射导弹 4 枚 |
| 海盗船 | 水面单位 | 1 | 1×3 直线 | 2 | 成功命中作战单位时自损 1；每次实际受伤使己方航空母舰联动损失 0.5 |
| 摩托艇 | 水面单位 | 2 | 每艘 1×1 | 1 | 两艘分别行动；命中水面单位或诱饵鱼雷后行动来源沉没 |
| 核潜艇 | 水下单位 | 1 | 2×2 方形 | 3 | 核弹 2 枚、震爆弹 1 枚、探测弹 1 枚 |
| 航空母舰 | 水面单位 | 1 | 5、6 或 8 格四向连通 | 5、6 或 8 | 自带首回合雷达扫描；直升机扫射 1 次；沉没即落败 |
| 诱饵鱼雷 | 水下部署物 | 2、3 或 5 | 每个占 1 格 | — | 伪装水下信号、消耗攻击并参与终局手动引爆 |

占地格数和生命值是独立属性。一次攻击对一个单位格造成的伤害由具体行动决定，不以舰艇占地格数直接计算。

## 7. 部署规则

1. 驱逐舰Ⅰ、驱逐舰Ⅱ和海盗船只能横向或纵向连续放置，不能弯折、斜放或拆散。
2. 潜水艇和核潜艇必须保持完整 2×2 方形。
3. 航空母舰按地图档位占 5、6 或 8 格；全部单位格必须通过上、下、左、右边相连形成一个整体。仅斜角相接不算连通。
4. 摩托艇和每个诱饵鱼雷各占 1 格；雷达不是部署对象，不占地图格。
5. 所有作战单位和部署物必须完全位于地图内。
6. 任意两个作战单位或部署物不能占用同一格。
7. 不同对象可以上下左右相邻或斜角相邻。
8. 玩家可以拖动、旋转、撤回单位，也可以使用随机部署。
9. 随机部署必须满足本节全部规则。

## 8. 回合与行动通则

1. 玩家按服务器固定座位顺序循环获得回合，三人局跳过已出局玩家。
2. 双人局中，一个正常回合完成一次合法行动后结束。
3. 三人局中，一个正常回合原则上需要对每名仍在局敌方玩家分别完成一次行动。A 的回合若 B、C 均仍在局，则 A 必须分别对 B 和 C 各操作一次；B、C 的回合同理。
4. 三人局两次行动的类型可以任意合法组合，行动来源也可以相同或不同。例如可以“驱逐舰攻击 B + 潜射导弹攻击 C”，也可以“震爆弹作用 B + 核弹攻击 C”。每次行动仍独立执行原有合法性、弹药和伤害规则。
5. 同一回合中，某名敌方玩家一旦完成一次行动结算，就不能再次作为普通行动目标；另一名尚未完成的敌方玩家仍需完成本回合操作。
6. 若某名原本需要操作的敌方玩家在本回合中出局、投降或因其他规则被移出在局集合，则其不再属于本回合剩余目标。
7. 若行动方在完成部分目标后已经没有任何能够作用于剩余目标的合法行动，则本回合结束，不强制生成不存在的行动。
8. 三人局直升机扫射是本节的全局例外：若在本回合使用直升机扫射，则同一行或同一列同时作用于全部仍在局敌方玩家，并一次性视为完成对所有敌方玩家的本回合操作。为了避免额外获得第三次效果，直升机扫射必须作为该回合的首个且唯一行动；若已经先对某名敌人完成普通行动，本回合不能再使用直升机扫射。只剩一名敌人时按普通单目标规则执行。
9. 非法请求不消耗行动机会，服务器返回具体错误原因。
10. 玩家不能主动跳过仍存在合法操作的回合。
11. 震爆弹只使作用区域内的水下单位瘫痪，不直接跳过该玩家的整个回合；水面单位和未瘫痪的水下单位仍可正常发动行动。
12. 每次行动必须指定一个仍存活且未瘫痪的行动来源；有限行动还必须具有剩余弹药。
13. 若当前玩家没有任何可用于本回合剩余目标的合法行动，该回合由服务器自动结束或跳过，且不计为主动放弃。
14. 行动来源在一次行动中因自身伤害沉没时，该行动仍完整结算；若本回合还有另一名敌方玩家需要操作，则由结算后的最新舰队状态继续判断可用行动。
15. 重复提交相同的行动编号只结算一次。
16. 震爆弹、探测弹和雷达扫描属于辅助行动，其余舰艇行动属于攻击行动。
17. 每名玩家在本局取得的第一个正常回合，其第一项操作必须使用航空母舰自带雷达扫描。双人局完成扫描后回合结束；三人局雷达只作用于所选的一名敌方玩家，随后该玩家仍需在同一回合对另一名仍在局敌方玩家完成一次合法操作。
18. 一个三人正常回合的 90 秒行动时限覆盖该玩家本回合的全部操作；完成第一名敌方玩家的操作后不重新获得 90 秒。
19. 震爆造成的瘫痪在该玩家整个正常回合结束后解除，而不是在三人局的第一项操作后提前解除。

## 9. 目标格与攻击范围通则

1. 除驱逐舰冲撞外，单格攻击的攻击范围均为敌方整张当前尺寸地图。
2. 除驱逐舰冲撞外，单格攻击可以重复选择合法范围内的目标格；同一单位格只具有一次伤害资格。
3. 范围攻击处理范围内全部格，包括此前已经结算的格；已受击单位格不会再次触发伤害。
4. 重复攻击只改变本次公开反馈，不清除原有地图历史；潜射导弹仍只留下“导弹已发射”标记。
5. 震爆弹和探测弹不产生已结算格，可以与此前的攻击或探测区域重叠。
6. 攻击范围超出地图的部分直接舍弃，不环绕，也不把范围整体向地图内平移。
7. 所有玩家地图使用相同坐标系。驱逐舰在己方地图上的中心坐标，直接用于确定其在当前所选敌方玩家地图上的可选目标范围。
8. 两艘驱逐舰共享“已由驱逐舰攻击的坐标”记录；双人局按对手记录，三人局按“敌方玩家＋坐标”分别记录。任一驱逐舰攻击某名敌方玩家的某坐标后，两艘驱逐舰均不得再次选择该敌方玩家的该坐标；另一名敌方玩家的同名坐标仍可选择。

### 9.1 驱逐舰Ⅰ的动态奇数攻击范围

驱逐舰Ⅰ第二格是中心格。10×10、12×12、15×15 地图分别使用沿舰身 9/11/13 格、垂直舰身 5/7/9 格的奇数范围，中心格两侧对称延伸：

```text
横向部署：|目标行-r|≤(垂直边长-1)/2 且 |目标列-c|≤(沿舰身边长-1)/2
纵向部署：交换上述行列限制
```

该集合与地图取交集，超出部分直接裁切。

### 9.2 驱逐舰Ⅱ的动态偶数攻击范围

驱逐舰Ⅱ以第二、第三格的几何中心为中心。10×10、12×12、15×15 地图分别使用沿舰身 8/10/12 格、垂直舰身 6/8/10 格的偶数范围。偶数边长统一向较小坐标方向延伸 `尺寸/2-1` 格，向较大坐标方向延伸 `尺寸/2` 格，再裁切地图外部分。

```text
横向部署：垂直边长行 × 沿舰身边长列
纵向部署：沿舰身边长行 × 垂直边长列
```

该取整规则保证不同客户端和服务端得到完全相同的离散范围。

## 10. 各项行动的唯一结算规则

### 10.1 驱逐舰Ⅰ冲撞

- 行动来源：存活的驱逐舰Ⅰ；
- 使用次数：不限；
- 目标：其当前地图档位攻击范围内、尚未被任一驱逐舰攻击的 1 格；
- 命中存活作战单位：目标单位受到 1 点伤害，驱逐舰Ⅰ同时受到 0.5 点伤害；
- 命中诱饵鱼雷：诱饵鱼雷被摧毁，驱逐舰Ⅰ受到 1 点伤害；
- 命中空海域或残骸：显示“未命中”，行动方与防守方均不受伤害。

### 10.2 驱逐舰Ⅱ冲撞

- 行动来源：存活的驱逐舰Ⅱ；
- 使用次数：不限；
- 目标：其当前地图档位攻击范围内、尚未被任一驱逐舰攻击的 1 格；
- 命中存活作战单位：目标单位受到 1 点伤害，驱逐舰Ⅱ同时受到 0.5 点伤害；
- 命中诱饵鱼雷：诱饵鱼雷被摧毁，驱逐舰Ⅱ受到 1 点伤害；
- 命中空海域或残骸：显示“未命中”，行动方与防守方均不受伤害。

### 10.3 海盗船攻击

- 行动来源：存活的海盗船；
- 使用次数：不限；
- 目标：敌方地图中的任意 1 格；
- 成功命中任意存活作战单位：目标受到 2 点伤害，海盗船自损 1 点；
- 命中诱饵鱼雷：诱饵鱼雷被摧毁，海盗船受到 1 点鱼雷爆炸伤害；不再额外计算“成功命中单位”的自损；
- 命中空海域或残骸：显示“未命中”，目标、行动方与防守方航空母舰及海盗船均不受伤害；
- 海盗船无论因主动攻击自损、诱饵爆炸、敌方攻击、范围攻击或终局鱼雷而实际失去生命值，己方航空母舰在该次行动或该轮同时结算中联动损失 0.5；同一次行动只触发一次联动；
- 目标伤害、海盗船伤害和航空母舰联动伤害属于同一次行动并完整结算；
- 结算后只有敌方航空母舰沉没时，海盗船一方获胜；
- 结算后只有己方航空母舰沉没时，海盗船一方失败；
- 二人局中结算后行动方与防守方航空母舰同时沉没时，按海盗船特殊规则判海盗船行动方获胜；三人局按剩余未出局玩家集合判定。

### 10.4 摩托艇冲撞

- 行动来源：存活的摩托艇；
- 使用次数：不限；
- 目标：敌方地图中的任意 1 格；
- 命中航空母舰：显示“命中”，航空母舰受到 1 点伤害，摩托艇同时受到 1 点伤害；
- 命中驱逐舰Ⅰ、驱逐舰Ⅱ、海盗船或摩托艇：显示“命中”，目标单位不受伤害，摩托艇受到 1 点伤害；
- 命中诱饵鱼雷：显示“命中”，诱饵鱼雷被摧毁，摩托艇受到 1 点伤害；
- 目标为潜水艇或核潜艇：显示“未命中”，行动方与防守方均不受伤害；
- 目标为空海域或残骸：显示“未命中”，行动方与防守方均不受伤害；
- 诱饵鱼雷虽然属于水下部署物，但属于摩托艇冲撞的明确例外目标；
- 因初始生命值为 1，摩托艇首次命中水面单位或诱饵鱼雷后立即沉没。

### 10.5 潜射导弹

- 行动来源：存活的潜水艇；
- 初始弹药：4 枚；
- 每次消耗：1 枚；
- 目标：敌方地图中的任意 1 格，可重复选择；
- 命中任意存活作战单位：目标单位受到 1 点伤害；
- 命中诱饵鱼雷：诱饵鱼雷被摧毁；
- 命中空海域或残骸：不造成任何伤害；
- 结算后，发射方只在目标格看到“导弹已发射”，不知道命中、未命中、目标类型、伤害和沉没情况；
- “导弹已发射”只是潜射标记，不是“命中”或“未命中”结论；该格仍可再次成为单格攻击目标，后续范围攻击也照常结算该格；
- 防守方始终收到“行动方使用潜射导弹攻击了某格”的通知；
- 若命中防守方作战单位，防守方在己方地图和状态卡中正常看到该单位受伤；若命中诱饵鱼雷，防守方正常看到该诱饵鱼雷被摧毁；
- 若未命中，防守方除行动名称和目标格外，不收到其他结果信息。

### 10.6 核弹

- 行动来源：存活的核潜艇；
- 初始弹药：2 枚，两枚规则完全相同；
- 每次消耗：1 枚；
- 目标：敌方地图中的任意 1 格，可重复选择；
- 命中航空母舰：航空母舰受到 2 点伤害；
- 命中其他存活作战单位：目标单位受到 1 点伤害；
- 命中诱饵鱼雷：诱饵鱼雷被摧毁；
- 命中空海域或残骸：显示“未命中”。
- 核弹与潜射导弹相同，不向发射方报告命中、未命中、目标类型、伤害或沉没；发射方只看到“核弹已投放”目标标记，防守方正常看到己方实际状态变化。

### 10.7 震爆弹

- 行动来源：存活的核潜艇；
- 初始弹药：1 枚；
- 每次消耗：1 枚；
- 目标：选择一个能使当前档位震爆区域完整位于地图内的中心格；10×10、12×12、15×15 分别为 5×5、5×5、7×7；
- 瘫痪判定：作用区域只要覆盖某个存活水下单位的至少一个单位格，该水下单位整体进入瘫痪状态；
- 影响对象：只有潜水艇和核潜艇可以被瘫痪；驱逐舰Ⅰ、驱逐舰Ⅱ、海盗船、摩托艇、航空母舰、诱饵鱼雷、残骸和空海域均不受影响；
- 持续时间：瘫痪状态在防守方下一个正常回合生效。该回合内，瘫痪单位不能作为行动来源；未瘫痪单位仍可正常行动；
- 解除时点：防守方该回合因其他单位完成行动，或因不存在合法行动而自动跳过后，本次震爆造成的全部瘫痪状态立即解除；
- 若防守方所有具有可用行动的单位均被瘫痪，该回合自动跳过且不计为行动超时；
- 施加方只知道自己使用了震爆弹及所选中心格和作用区域，不显示“震爆成功”或“震爆失败”，也不公开受影响单位的数量、类型或坐标；
- 防守方从己方地图和单位状态中看到哪些己方单位处于瘫痪状态；
- 本行动不造成伤害，不产生“命中”或“未命中”结论，也不使作用区域内的格成为已结算格。

### 10.8 探测弹

- 行动来源：存活的核潜艇；
- 初始弹药：1 枚；
- 每次消耗：1 枚；
- 目标：选择一个中心格，使当前三个地图档位均为 3×3 的作用区域完整位于地图内；
- 潜水艇或核潜艇的未受击存活单位格，以及未被摧毁的诱饵鱼雷，均产生水下信号；
- 区域内至少存在一个水下信号时，仅返回“探测到水下信号”；否则返回“未探测到水下信号”；
- 不返回信号数量、具体坐标或对象类型；
- 本行动不造成伤害。

### 10.9 直升机扫射

- 行动来源：存活的航空母舰；
- 初始次数：1 次；
- 每次消耗：1 次；
- 解锁条件：己方驱逐舰Ⅰ和己方驱逐舰Ⅱ均已沉没；其他玩家驱逐舰的状态不影响解锁；
- 未解锁时，直升机扫射不属于合法行动，也不计入己方现有攻击手段；
- 目标：选择敌方地图中的完整一行或完整一列；
- 作用区域：该行或该列的 N 格；
- 对每个尚未结算的格分别结算；
- 目标格为存活水面单位的单位格时，显示“命中”并造成 1 点伤害；
- 同一次直升机扫射对航空母舰造成的总伤害最多为 2 点；若覆盖三个及以上尚未结算的航空母舰单位格，所有这些格仍分别显示“命中”并成为已受击单位格，但航空母舰本次最多扣除 2 点生命值；
- 目标格为水下单位、诱饵鱼雷、空海域或残骸时，显示“未命中”，不造成伤害，也不摧毁诱饵鱼雷；
- 每个格分别向攻击方显示“命中”或“未命中”，但不显示对象类型；
- 已结算格不再次造成伤害，其原有标记保持不变。
- 双人局中，直升机扫射只作用于唯一敌方玩家。
- 三人局中，若两名敌方玩家均仍在局，玩家选择一行或一列后，该同一行或同一列同时在两张敌方地图上独立结算；每张敌方地图分别生成命中、未命中和伤害记录。
- 三人局一次直升机扫射只消耗 1 次直升机使用次数，并一次性完成本回合对全部仍在局敌方玩家的操作；不能在本回合先执行普通行动后再追加直升机扫射。

## 11. 伤害、沉没与信息公开

1. 所有伤害最低将生命值扣至 0，不记录负生命值。
2. 一次范围攻击同时计算全部命中；同一作战单位被命中的多个未受击单位格分别造成伤害，但总伤害不超过该单位结算前的剩余生命值。若具体行动另有单次总伤害上限，还不得超过该上限；直升机扫射对航空母舰的单次总伤害上限为 2 点。
3. 一个单位格在攻击结算开始时属于存活作战单位且被攻击覆盖，就成为已受击单位格；该格今后仍可成为目标，但不能再次触发基于该目标格的目标伤害、攻击者自损或海盗船航母连带伤害。潜射导弹实际命中的单位格同样适用本规则。
4. 海盗船受伤引发的己方航空母舰 0.5 联动伤害不对应敌方目标格；只要海盗船在该次行动中实际受伤即可触发一次。
5. 作战单位生命值降至 0 时立即沉没，其所有单位格在防守方地图上显示为残骸。
5. 攻击方不会收到“单位沉没”提示，也不会看到舰种、剩余生命值或完整轮廓。
6. 攻击方只保留自己已经获得的逐格“命中”或“未命中”结果以及潜射标记；沉没单位尚未被攻击的其他单位格不自动标记。
7. 沉没单位不再产生信号，也不再承受伤害。其尚未结算的残骸格今后受到攻击时按“未命中”处理。
8. 诱饵鱼雷被摧毁时，攻击方只得到“命中”结果，不公开其真实身份；防守方从己方地图上看到该诱饵鱼雷已失效。
9. 除潜射导弹和核弹外，单格攻击命中时只公开“命中”，不公开实际造成的伤害值。
10. 潜射导弹和核弹均不向发射方公开结算结果；防守方只额外看到己方实际发生的状态变化。
11. 除潜射导弹、核弹、探测弹、震爆弹和直升机扫射的既定反馈外，所有行动都记录行动名称、公开目标和公开结果；潜射导弹与核弹的公开记录只包含行动名称和目标格。
12. 震爆弹的公开记录只包含行动名称、中心格和当前档位作用区域，不包含成功、失败或任何受影响单位信息；防守方仅在己方状态中看到实际瘫痪结果。

## 12. 敌方地图状态与私人标记

敌方地图中的三种互斥基础状态为：

- 未知：尚未结算；
- 命中：该格曾返回“命中”，但对象身份未知；
- 未命中：该格曾返回“未命中”。

以下信息独立覆盖在基础状态之上：

- 潜射标记：显示“导弹已发射”，表示潜射导弹曾以该格为目标，不表示结算结果；
- 核弹标记：显示“核弹已投放”，表示核弹曾以该格为目标，不表示结算结果；
- 水下探测区域：仅记录探测弹曾覆盖的 3×3 区域及其布尔结果；
- 震爆区域：仅记录震爆弹曾覆盖的当前档位区域和发生回合，不记录成功或失败结果。
- 雷达区域：记录雷达曾扫描的当前档位区域及“发现布局/未发现布局”的布尔结果，不记录数量、层级、坐标或类型。

潜射标记和核弹标记可以与“未知”基础状态并存；这些格仍可被其他单格攻击再次选择，范围攻击也照常处理。若后续公开行动返回“命中”或“未命中”，地图以该结论作为基础状态，隐藏武器历史仍保留在行动记录中。

攻击方不显示“沉没”状态。玩家可以在未知格使用五种本机私人标记：确定有布局（整格红）、水面有布局（上半红）、水面无布局（上半白）、水下有布局（下半红）、水下无布局（下半白）。私人标记不消耗回合、不改变公开状态且对手不可见；玩家可循环切换或清除。公开状态由服务器生成，玩家不能手动修改。

### 12.1 航空母舰雷达扫描

- 雷达是航空母舰自带功能，不是单位或部署物，不占格、无生命值且不能成为目标；
- 每名玩家取得的第一个正常回合，其第一项操作强制扫描一次；双人局扫描后结束回合，三人局扫描只完成所选敌方玩家的一次操作，仍需对另一名仍在局敌方玩家完成本回合操作；
- 目标以左上角格表示，必须形成当前档位的完整 3×3、4×4 或 5×5 区域；
- 区域内存在任一作战单位或仍有效的诱饵鱼雷时，返回“发现布局”，否则返回“未发现布局”；
- 结果不公开对象数量、具体坐标、水面/水下层级、舰种或生命值。

## 13. 诱饵鱼雷与终局手动引爆

### 13.1 对局中的诱饵效果

- 诱饵鱼雷属于水下部署物，不具有生命值；
- 探测弹会把未被摧毁的诱饵鱼雷识别为水下信号；
- 驱逐舰冲撞、海盗船攻击、摩托艇冲撞和核弹命中诱饵鱼雷时，将其摧毁并向攻击方返回“命中”；
- 潜射导弹命中诱饵鱼雷时将其摧毁，但发射方仍只看到“导弹已发射”，不知道是否命中或目标身份；
- 直升机扫射不能命中或摧毁诱饵鱼雷；扫过其所在格时返回“未命中”；
- 诱饵鱼雷的真实身份和摧毁状态不向攻击方公开；
- 诱饵鱼雷不是作战单位，不会被震爆弹瘫痪。

### 13.2 所有仍在局玩家无攻击手段的判定

“无攻击手段”指某名仍在局玩家不存在任何满足以下条件的攻击行动：

1. 行动来源仍然存活；
2. 若行动需要弹药，则仍有剩余弹药；
3. 该行动的攻击范围内至少存在一个规则允许选择的合法目标；允许重复攻击的行动按其原有重复攻击规则判断。
4. 若行动具有额外解锁条件，则该条件已经满足。

震爆弹、探测弹和首回合雷达属于辅助行动，不计入攻击手段。瘫痪是临时状态，不会永久移除攻击手段；判断是否进入终局手动引爆时忽略当前瘫痪状态。每次行动结算后，服务器检查所有仍在局玩家是否均无攻击手段。

### 13.3 终局手动鱼雷引爆

所有仍在局玩家均无攻击手段时进入交互式终局阶段。每轮所有仍在局玩家秘密提交一枚尚未触发的己方诱饵鱼雷；本轮全部提交完成后同时结算。

1. 双人局中，每枚被选中的诱饵鱼雷以其己方坐标攻击唯一对手地图中的同名坐标。
2. 三人局中，每枚被选中的诱饵鱼雷以其己方坐标，同时攻击其他所有仍在局玩家地图中的同名坐标。例如 A 选择位于 `G10` 的诱饵鱼雷，则同一轮同时检查 B 的 `G10` 与 C 的 `G10`。
3. 三人局的这一“同时攻击所有其他仍在局玩家”是终局鱼雷的固定例外，不再按座位顺序只攻击下一名玩家。
4. 每轮每名玩家只选择一枚己方鱼雷；没有可用鱼雷的玩家由服务器自动跳过。
5. 命中敌方存活作战单位时造成 1 点伤害；命中空海域、残骸或部署物时不造成伤害。
6. 同一轮的所有鱼雷选择先收集、后统一结算，后提交者不能提前看到其他玩家选择；三人局同一枚鱼雷对两名敌人的检查也属于同一轮同时结算。
7. 已引爆鱼雷从后续可选列表移除，然后开始下一轮。
8. 全部可用鱼雷处理完后比较所有仍在局玩家航空母舰生命值；唯一最高者获胜，最高值并列则平局；即使中途有航空母舰降至 0，也完成剩余鱼雷后再比较。

## 14. 超时、断线、投降与对局结束

### 14.1 行动超时

- 每个正常回合的行动时限为 90 秒；三人局两次面向不同敌人的普通操作共享同一个 90 秒截止时间，第一项操作完成后不重置计时；
- 若截止时间到达时本回合仍未完成，则当前回合结束，尚未提交的剩余敌方操作不自动执行；已经完成的前序操作不会回滚；
- 同一玩家连续三个实际行动回合超时，自动判负或在三人局出局；
- 只有完整完成本回合所需操作，或因规则导致已无剩余合法目标/行动而正常结束回合时，才把该玩家此前的连续超时次数清零；
- 自动跳过的回合不计入连续超时。

### 14.2 断线重连

- 对局开始前断线：保留座位 120 秒；超时未返回则关闭房间，不判胜负；
- 对局开始后任一仍在局玩家断线：暂停对局并开始该玩家的 120 秒重连倒计时；
- 断线玩家在时限内使用本机重连凭证返回后继续对局；
- 某玩家超过 120 秒未返回时，该玩家在双人局判负、在三人局出局；若对局因此只剩一名未出局玩家则结束；
- 所有仍在局玩家均离线且都未在各自 120 秒期限内返回时，对局取消，不判胜负；
- 首版不支持换设备恢复原座位。

### 14.3 投降

玩家可以在对局开始后的任何时刻投降；二次确认后立即判负。

### 14.4 结算与再来一局

1. 结算页显示胜负原因、回合数和对局时长。
2. 对局结束后向本房间玩家公开所有参战玩家的完整部署、最终生命值、剩余弹药和行动记录。
3. 房间内所有保留席位的玩家都选择“再来一局”且全部在线后返回部署阶段，重新部署并重新掷骰决定先手。
4. 赛后任一玩家离开时，其余玩家保留在原房间并回到等待阶段；房主离开时由剩余席位中的第一名玩家继任房主，可继续等待补满原定 2 人或 3 人席位。

## 15. 服务器权威与合法性验证

- 其他玩家的完整部署只保存在服务器，不发送给无权查看的浏览器；
- 服务器是回合、随机数、生命值、弹药、命中、沉没和胜负的唯一权威；
- 客户端只提交行动意图，不能直接修改任何战局数值；
- 房间码只用于加入房间，不作为身份凭证；每位玩家另有私密重连凭证；
- 服务器拒绝越界、重叠部署、非本人回合、无效行动来源、超出攻击范围、弹药不足，以及已沉没或正处于瘫痪状态的单位发动行动等请求；重复攻击合法，但服务器强制执行每格一次伤害资格。

### 15.1 三人模式回合与出局

1. 三人按服务器固定座位顺序循环获得回合；掷骰只决定循环从谁开始。
2. 当另外两名玩家均仍在局时，当前玩家的普通回合需要分别对两名敌方玩家各完成一次操作；两次操作属于同一个玩家回合，不在中间切换行动玩家。
3. 两次操作可以使用任意合法行动组合，并分别执行原有弹药、行动来源、攻击范围、伤害和隐藏信息规则。
4. 每项普通操作必须明确选择一名本回合尚未完成操作的仍在局敌方玩家；同一回合不能对同一名敌人连续执行两项普通操作来替代另一名敌人的操作。
5. 每名敌方玩家拥有独立的敌方地图记录。对 B 的命中、未命中、驱逐舰已攻击坐标、潜射标记、核弹标记、探测/震爆/雷达区域和私人标记，不得错误写入 C 的敌方地图；反之亦然。
6. 直升机扫射是普通回合的多目标例外：作为本回合首个且唯一行动时，同一行或同一列同时作用于所有仍在局敌方玩家，并一次性完成全部敌方操作要求。
7. 航空母舰沉没、投降、连续三个实际行动回合超时或断线超时均使该玩家出局；出局玩家不再取得行动回合，也不再属于其他玩家本回合尚需操作的目标。
8. 仍有两名玩家时对局继续，此后每个回合只需对唯一仍在局敌人完成一次操作；直升机退化为普通单目标扫射。
9. 同一行动使两名玩家同时出局时，以结算后的未出局玩家集合判定；只剩一人则该玩家获胜，无人存活则平局。
10. 所有仍在局玩家无攻击手段后进入终局手动鱼雷阶段；三人局每枚被手动引爆的己方鱼雷同时作用于其他所有仍在局敌方玩家的同名坐标。

### 15.2 行动消息分级

每次行动生成三种互不混用的消息：

- 行动方消息：对于会公开命中的武器，显示目标单位名称、实际伤害和结算后生命值；同时完整显示己方自损及己方联动伤害。
- 防守方消息：只显示己方哪个单位“被命中”或“被命中并沉没”，不在战报文字中发送生命值变化；己方地图和单位状态卡仍显示最新权威生命值。
- 第三方消息：只显示行动方、行动名称、被选择的防守方、公开目标和规则允许的公开结果；不发送任何一方生命值、伤害事件或私密目标类型。
- 潜射导弹和核弹继续执行原有保密优先级：行动方不获得命中、目标类型、伤害或沉没信息。
- 震爆弹不向施加方或第三方报告是否生效；探测弹和雷达只向行动方返回规则规定的布尔结果。

## 20. Ocean-v1.2 人机对战规则

### 20.1 模式边界

1. 人机对战固定为一名真人对一名服务器机器人，属于双人对局。
2. 三人自由战不得加入机器人；不提供三人人机或机器人互战。
3. 人机房创建后机器人立即占据第二席位，其他真人不能通过房间码加入。
4. 除本节明确规定的自动操作外，舰队、行动、伤害、信息隐藏、胜负和终局规则与双人联机完全相同。

### 20.2 公平信息边界

1. 机器人由服务器运行，但决策器只能接收机器人自己的安全玩家视图。
2. 决策器可使用己方部署、生命值、弹药、瘫痪状态、公开行动记录、私人雷达/探测结果和自己的敌方地图记录。
3. 决策器不得读取真人完整部署、隐藏单位类型、隐藏生命值、未触发诱饵位置、潜射导弹或核弹的隐藏命中结果，以及震爆弹是否成功。
4. 真人与机器人收到的行动消息继续遵守行动方、防守方信息分级；对手是机器人不构成额外公开理由。

### 20.3 自动流程

1. 机器人使用服务器随机合法部署，并自动准备。
2. 真人每轮主动掷骰后，机器人自动提交该轮掷骰意图；点数仍由服务器随机生成。同点时双方进入下一轮。
3. 机器人第一个正常回合必须使用当前地图档位对应的雷达，此后仅从当时的合法行动和合法目标中选择。
4. 机器人行动具有短暂展示延时，不因思考延时触发行动超时；机器人不会断线、投降或累计连续超时。
5. 机器人无合法行动时使用既有 AUTO_SKIPPING；瘫痪及解除规则不变。
6. FINAL_SALVO 每轮中机器人只根据己方可用诱饵和安全情报秘密选择，不得读取真人本轮选择。
7. 真人申请再来一局时机器人自动确认；双方重新部署、重新掷骰并清空全部旧情报。

### 20.4 标准机器人策略

1. 机器人维护任意布局、水面目标和水下目标三类格点评分。
2. 雷达阳性区域提高布局概率，阴性区域降低布局概率；探测弹结果只更新水下判断。
3. 公开命中格不再作为主要伤害目标，并提高其上下左右及直线延伸格的优先级。
4. 潜射导弹和核弹使用后只能记录曾经尝试，不得用隐藏结算修正判断。
5. 驱逐舰遵守共享坐标限制；其余允许重复的武器也应尽量避免无意义重复攻击。
6. 摩托艇和直升机偏向高水面概率目标；震爆弹偏向水下信号阳性区域；探测弹偏向信息覆盖价值高的未知区域。
7. 海盗船会结合己方航空母舰生命值降低高风险行动优先级，但在只剩该攻击手段时仍可使用。
8. 同分或接近候选加入有限随机扰动，使不同对局不会形成完全固定的行动序列。

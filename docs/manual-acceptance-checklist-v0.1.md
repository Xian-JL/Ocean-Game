# 《海战 OCEAN》阶段 8 双窗口人工联调清单 v0.1

> 环境：Edge 普通窗口（甲）+ Edge InPrivate 窗口（乙）  
> 地址：http://127.0.0.1:3000  
> 记录方式：每项填写“通过”或现象截图；出现失败即停止进入下一阶段。

## A. 房间与部署

- [ ] INT-01：甲创建房间进入 P02，乙使用房间码加入，双方进入 P03。
- [ ] INT-02：双方互相看不到对方部署；随机部署、清空、撤销和旋转可正常使用。
- [ ] INT-03：一方准备后仍能看到对方未准备；双方准备后进入 P04，再进入 P05。
- [ ] INT-04：双方看到同一掷骰轮次、点数和唯一先手。

## B. 对战与保密

- [ ] INT-05：非当前玩家的九项行动全部锁定，当前玩家只开放合法行动。
- [ ] INT-06：普通命中只在攻击方敌图显示命中，不显示舰种；防守方己图显示实际受伤。
- [ ] INT-07：潜射导弹发射方只见“导弹已发射”，该格仍可再次单格攻击，范围攻击不跳过。
- [ ] INT-08：震爆弹施加方不知道是否生效；只有防守方被覆盖的水下作战单位在其回合显示瘫痪。
- [ ] INT-09：探测弹只返回有/无水下信号，不显示数量、坐标或对象类型。
- [ ] INT-10：海盗船、摩托艇、驱逐舰、核弹和直升机的确认文案与 `rule-v1.0.md` 一致。

## C. 断线与计时

- [ ] INT-11：关闭一方页面或断网后，另一方进入 O02，当前行动不可继续。
- [ ] INT-12：在 120 秒内重新打开原浏览器环境，座位和服务器确认状态恢复，O02 消失。
- [ ] INT-13：恢复后仍是正确玩家的正确回合，没有重复结算或额外消耗次数。
- [ ] INT-14：行动倒计时到 30 秒和 10 秒时提示明显；客户端不会自行宣布超时结果。

## D. 终局与后续

- [ ] INT-15：完成一局后双方进入 P06，胜负视角相反但原因、回合数和最终生命值一致。
- [ ] INT-16：P06 才能查看双方完整部署、真实单位身份、资源和完整行动复盘。
- [ ] INT-17：单方申请再来一局不会提前重置；双方确认后回到全新 P03。
- [ ] INT-18：新局投降后双方进入 P06；投降方赛后离开回 P01，留下方回 P02。
- [ ] INT-19：测试双方无攻击手段时的终局鱼雷齐射，展示期间操作锁定，齐射全部完成后才进入 P06。

## E. 页面与设备

- [ ] INT-20：桌面可同时阅读双地图；缩窄窗口后地图标签、行动抽屉和日志折叠正常。
- [ ] INT-21：只用 Tab、Enter、Space 可以打开规则、选择行动、选格、取消和确认。
- [ ] INT-22：命中、未命中、潜射、瘫痪和禁用状态不只依赖颜色。
- [ ] INT-23：浏览器地址、页面、控制台公开日志中均无 `reconnectToken` 或可复用凭证。

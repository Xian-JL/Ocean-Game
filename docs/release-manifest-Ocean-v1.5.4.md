# Ocean-v1.5.4 发布清单

基线：Ocean-v1.5.3。npm：1.5.4。规则：rule-v1.8。页面流程：page-flow-v2.1。Socket：2.1。

## 第二批2.5D战斗反馈素材

本版本接入 48 项透明反馈素材，并保留其来源清单 `ocean-v1.5.4-second-assets-source-manifest.json`。原始 1254×1254 PNG 经等比例压缩为透明 512×512 WebP 运行资源；48项合计约 3 MB，不修改第一批57项舰体与海面资源。

- 14 项格子反馈：部署合法/禁用、目标预览、雷达/探测/震爆范围、命中/未命中、低生命、私人标记等。
- 12 项舰体状态：轻/重损、瘫痪、低血、沉没、诱饵、选中锁定等，均只基于己方已经可见的舰队状态显示。
- 14 项特效：导弹、核弹、震爆、雷达、声呐、直升机、爆炸与水花显示在已可见的实时反馈条；导弹、核弹、震爆仍不会因此暴露命中结果。
- 8 项战术道具：按实际占格为舰体增加阴影与航迹；雷达反馈加入信标，目标预览加入箭头。

## 边界与兼容性

不改变地图坐标、点击区域、行动数值、结算、AI、服务器权威性、Socket 2.1 或敌方安全视图。第二批艺术仅绑定客户端现有的合法状态；敌方未知地图仍不渲染舰体。满幅中央沙盘、经典按钮样式、右侧行动面板和移动端布局继续保留。

## 验收

`npm run acceptance` 通过：376项测试，pass 376 / fail 0 / skipped 0；53组生产音效 OGG/MP3 校验、环境、语法、DOM交互、联机与整局流程均通过。新增回归验证48项资源、格子映射、状态/特效映射、保密边界和版本标识；详细输出见 `docs/acceptance-v1.5.4.txt`。

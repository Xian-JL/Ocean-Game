## 动效实现

十行动各有线、环、扫描或航迹的代码图形及独立时长；高画质750～1400ms，流畅200～340ms，减少动画保留静态事实。主效果同时最多1个、不排队，1800ms兜底清理；新事件、地图切换、重置/退出、减少动画和页面后台可取消。序号水位与有界去重避免同步、重绘、旧应答复播。

动作输入沿用角色过滤后的battleEffectModel。导弹、核弹、震爆的攻击方保持结果未知，侦察仅呈现允许的布尔结论。音效由新的安全结算事件触发，提交ACK不重复播放；异步音频超过时效不补播，取消会终止临时音源。结算页优先于旧战斗特效。

短反馈覆盖16项页面交互，包括座位、部署选择/落位、目标、标记、切图/层、抽屉、教程与连接；己方HP、资源、沉没、鱼雷失效与瘫痪/恢复由安全差分触发，数字立即更新。回合、骰子、齐射完成和结算也有独立短效。重绘保留短反馈剩余时间。环境只允许单层低幅度慢移；自动画质连续两窗口过慢时降为流畅，不来回升级。效果层pointer-events:none，不改变目标格、海图布局或服务器结算。

# Ocean-v1.5.9 发布清单

基线：Ocean-v1.5.8。npm：1.5.9。规则：rule-v1.8。页面流程：page-flow-v2.1。Socket：2.1。

## 本版范围

- 主流手机：以390×844为主要验收视口，顶部只保留回合、计时和三人同步进度；中央始终显示单张地图；底部为行动、战斗日志、情报和系统消息四入口。
- 大型平板：以820×1180为主要验收视口，沿用移动端信息层级但提升地图纵向高度，行动和日志抽屉居中限宽。
- 平板横屏：以1180×820为主要验收视口，保留左侧战术入口、中央大沙盘、右侧行动面板和紧凑底部控制台。
- 电脑：以1920×1080为主要验收视口，保持v1.5.8完整驾驶舱布局和比例。

## 交互与可访问性

- 10×10、12×12、15×15在手机与竖屏平板统一使用42px棋格，超出可视区域时只在地图框内双向平移，不推动整页产生横向滚动。
- 移动端新增当前行动/目标常驻条；选定目标后可“回到目标”或直接重新打开确认框。
- 行动与日志底部抽屉互斥，遮罩位于地图之上；抽屉标题和目标确认区保持可见。
- 触控按钮不小于44px，底部控制区使用safe-area环境变量适配刘海、圆角屏和系统手势区。
- 减少动态效果设置继续生效。

## 冻结边界

- 不修改rule-v1.8规则、数值、AI策略、Socket 2.1或服务器权威结算。
- 不修改v1.5.8三人同步行动、安全视图、隐私隔离和结算反馈。
- 不新增或替换2.5D美术、音效资源。

`npm run acceptance` 已通过：407项测试，pass 407 / fail 0 / skipped 0；53组生产音效OGG/MP3校验、环境、语法、启动、DOM交互、联机与完整对局均通过。专项回归覆盖版本元数据、四档断点、42px地图内部平移、移动端常驻指令、抽屉互斥、触控尺寸、安全区、横屏平板布局和减少动态效果。验收摘要写入 `docs/acceptance-v1.5.9.txt`。

# Ocean-v1.5.2 发布清单

## 版本边界

- 产品版本：`Ocean-v1.5.2`
- npm SemVer：`1.5.2`
- 规则版本：`rule-v1.8`
- 页面流程：`page-flow-v2.1`
- Socket Protocol：`2.1`
- 代码基线：`Ocean-v1.5.1`

本版只接入第一批2.5D美术资源和相应表现层，不修改服务器规则、伤害数值、行动合法性、AI、安全信息投影或联机协议。

## 美术资源

1. 海面纹理（3项）
   - 深海暗夜：`ocean_deep_active.webp`
   - 极地寒光：`ocean_deep_calm.webp`
   - 黄昏余晖：`ocean_deep_subtle.webp`

2. 航空母舰模块（16项）
   - 每个航母格依据北、东、南、西四个方向是否存在同舰相邻格生成 `N/E/S/W` 四位连接码。
   - 运行时完整保留从 `N0E0S0W0` 到 `N1E1S1W1` 的16种模块。
   - 航母继续允许任意六格四向连通形状，不被美术层改成固定直线。

3. 其他单位（28项）
   - 驱逐舰Ⅰ、驱逐舰Ⅱ、海盗船、摩托艇、潜水艇、核潜艇和诱饵鱼雷各提供北、东、南、西四向图。
   - 直线舰艇与2×2水下单位按真实地图占格范围跨格渲染；单格单位保持单格投影。
   - 素材源中摩托艇东/南语义在预处理时校正，网页资源名以实际方向为准。

4. 行动图标（10项）
   - 两型驱逐舰冲撞、海盗船攻击、摩托艇冲撞、潜射导弹、核弹、震爆弹、探测弹、雷达扫描和直升机扫射全部接入右侧行动面板。

## 表现与安全边界

- 部署地图、己方战场和赛后公开复盘显示2.5D单位投影。
- 对局中的敌方地图不渲染隐藏单位，只保留公开命中/未命中、秘密武器占位提示、侦察区域和本机私人标记。
- 水面/潜层/综合只改变己方投影透明度，不发送 Socket 请求，不产生新情报。
- 受击、瘫痪、沉没和当前选中状态由 CSS 叠加，不复制服务器结算逻辑。
- 2.5D定位使用 `data-grid-row/column/span` 和预定义 CSS 映射，不使用动态内联样式，保持生产 CSP 兼容。

## 性能与兼容

- 57项核心素材均转为网页运行用 WebP；海面按2048×2048输出，单位与图标按实际显示尺寸缩放。
- 运行时资源总量控制在3 MB以内，原始高分辨率素材不直接进入首屏网络传输。
- v1.5.1 的地图完整显示、2.5°透视、经典按钮样式、右侧 v1.5 行动面板和900px以下移动端布局均保留。

## 验收要求

- 57项运行资源存在、非空、可识别为 WebP，源清单数量为57。
- 10×10、12×12、15×15 的整船投影均使用实际占格，不改变单元格点击坐标。
- 航母所有连接形态均有对应模块且连接码由四向邻接计算。
- 对局敌方安全视图没有单位美术层。
- 完整自动化测试、语法检查、生产音效校验、启动与整局流程通过。

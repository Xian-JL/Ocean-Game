# 《海战 OCEAN》postlaunch-v0.7.6 发布清单

> 版本：0.7.6  
> 阶段：postlaunch-v0.7.6  
> 规则：rule-v1.4  
> 页面流程：page-flow-v1.5  
> Socket Protocol：1.6

## 1. 发布定位

v0.7.6 是 v0.7.5 后的交互微调版，不修改既有战斗数值、攻击规则、三人双目标回合、独立敌方地图、直升机多目标、最终齐射、隐藏信息或胜负逻辑。

## 2. 主动掷骰

- 所有玩家准备后进入 ROLLING，但服务器不再自动完成整轮掷骰。
- 每名玩家每轮主动点击一次“掷骰子”。
- 客户端只提交掷骰意图，1～6 点随机结果继续由服务器生成。
- 玩家本轮提交后不能重复投掷。
- 全部玩家提交后判断唯一最高点。
- 最高点并列时，全员进入下一轮并再次主动投掷。
- 分出先手后，结果在原阶段展示时间基础上额外停留 3 秒再进入 PLAYING。
- 新增 Socket 事件：`match:roll-die`。

## 3. 兵种行动与状态融合

对战右侧不再把“行动列表”和“己方舰队状态”分成两个主要区域，而是按兵种建立融合卡片：

- 驱逐舰Ⅰ：HP / 状态 / 冲撞
- 驱逐舰Ⅱ：HP / 状态 / 冲撞
- 海盗船：HP / 状态 / 攻击
- 摩托艇：两艘实例 HP / 状态 / 冲撞
- 潜艇：HP / 状态 / 潜射导弹剩余量 / 发射
- 核潜艇：HP / 状态 / 核弹 / 震爆弹 / 探测弹
- 航空母舰：HP / 状态 / 雷达 / 直升机
- 诱饵鱼雷：保留数量状态，不增加普通回合行动入口

所有行动合法性仍来自服务器安全视图和既有前端状态派生，不在 UI 中复制规则引擎。

## 4. 必须保持不变

- 12×12 地图
- 2 人 / 3 人模式
- 三人每回合分别对两名敌人操作
- B/C 敌方地图独立记录
- 90 秒完整玩家回合
- 首次雷达规则
- 直升机多目标结算
- 终局鱼雷多目标结算
- 伤害、弹药、瘫痪、淘汰和胜负规则
- Actor / Defender / Observer 信息隔离

## 5. 发布验收

至少确认：

1. 每名玩家必须主动完成开局掷骰。
2. 同一玩家同轮不能重复掷骰。
3. 同点后可以进入下一轮再次投掷。
4. 掷骰随机值只能由服务器生成。
5. 结果额外展示 3 秒后进入对战。
6. 右侧每个兵种卡片同时可见单位状态和对应行动。
7. 两艘摩托艇保持独立状态展示。
8. 10 项既有行动入口全部保留。
9. v0.6.2 以来的战斗与隐藏信息测试继续通过。

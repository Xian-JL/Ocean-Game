# Ocean-v1.6.0 发布清单

基线：Ocean-v1.5.9。npm：1.6.0。规则：rule-v1.8。页面流程：page-flow-v2.1。Socket：2.1。

## 本版范围

### 2.5D画质与资源调度

- 个性化设置提供自动、高画质和流畅三档，本机保存，不进入Socket请求。
- 自动画质综合减少动态效果偏好、设备内存、处理器核心数和当前短边视口。
- 流畅档移除阴影、航迹、玻璃模糊与多层短时特效；必要状态素材继续显示。
- 当前海面、首次雷达、当前行动和高画质常用反馈在浏览器空闲时去重预热。
- 装饰素材使用低优先级延迟加载，舰体与即时结算使用异步解码和对应加载优先级。

### 地图操作与跨视口状态

- 己方及每名敌方地图分别保存滚动位置，切图和同页重绘后恢复。
- 浏览器尺寸或横竖屏发生变化时保存并按新边界恢复地图位置。
- 新增地图居中；回到目标支持单格、整行与整列目标。
- 非鼠标指针拖动地图超过12px后，650ms内抑制敌方格点击，避免拖图误选目标。
- 手机、大型竖屏平板、横屏平板和电脑继续使用v1.5.9确定的四档布局；末级覆盖独立放入 `public/css/v1.6.0.css`。

### 重连同步

- Socket重连或页面返回前台时先显示“正在同步”。
- 接受服务器新状态后恢复在线状态，并在暂停恢复场景说明当前行动方、剩余时间和本地目标是否保留。
- 继续依赖状态版本和结算键避免重复接收旧状态、重复播报或重复播放短时特效。

## 冻结边界

- 不修改rule-v1.8规则、数值、AI策略、Socket 2.1和服务器权威结算。
- 不修改三人同步行动、安全视图、结算隐私和终局流程。
- 不新增或替换第一、第二批2.5D美术和53组生产音效。

## 验收

执行 `npm run acceptance`。专项回归覆盖画质本地化、自动档判定、流畅档降级、资源预热、地图视图记忆、单格/行/列目标复位、拖图防误触、横竖屏恢复、四档末级CSS以及重连同步。53组生产音效双格式校验通过，419项自动化测试全部成功；最终结果见 `docs/acceptance-v1.6.0.txt`。

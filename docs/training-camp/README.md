# OCEAN 训练营

## 核心战斗体验

当前按用户新要求收敛为四步快速上手、十种行动试射和不计时的自由练习。舰队预先部署，陪练自动回应，玩家只需选择行动、瞄准并确认。界面移除场景编号、全部情况目录、角色切换、教官解析、虚拟时间和故障模拟。

详细实现、隔离边界与验证见[core-combat.md](core-combat.md)。旧90主题/163变体属于内部回归夹具，原manifest与历史交接保留追溯，不表示当前玩家入口仍提供开发者工具。

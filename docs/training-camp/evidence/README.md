## 复现

运行npm start，首页进入训练营，搜索CAMP-W01并进入。选择驱逐舰Ⅰ冲撞，点敌方B1，确认执行；看到敌图命中、己方驱逐舰Ⅰ3→2.5、任务已体验。点击教官解析并展开任务，能看到敌方驱逐舰Ⅱ3→2、己方自损0.5；重来后恢复初始检查点。手机模式先点“行动”打开抽屉，再进行相同步骤。

# 训练营：核心战斗体验

## 当前定位

2026-10-22，按用户最新要求收敛训练营。它是玩家的战斗练习入口。已发布v1.6.2的完整记录保留历史意义；本次修改位于本地工作区。

## 玩家流程

快速上手用四次实际操作学习开火、雷达、潜射导弹和最终齐射。点击开始即进入预部署战场，完成后可继续下一步或重来。十种武器以行动名称直接进入试射，不要求配置来源状态或目标种类。

自由练习是12×12、随机部署、不计时的正常战斗。玩家与陪练交替行动；陪练读取自己的安全视图自动决策，操作、资源、伤害和胜负仍由原规则结算。失败、胜利后可直接再练一次。

练习条只显示目标、简短解释、重来、继续和退出。场景编号、163变体目录、角色切换、教官全局解析、时间推进、断线模拟、检查点和调试表单退出用户界面。

## 接口与隔离

GET /api/training/course返回四步课程和十种武器的玩家文案。POST /api/training/sessions接受mode=course/weapon/free和公开lessonId。玩家会话只允许重来，不允许角色/时钟/故障/教官控制；默认服务不开放旧catalog或reveal接口。旧夹具仅在显式training.debug=true的内部测试服务使用。

自动陪练在玩家安全结果显示后发起独立推进请求，保留本方动作反馈。每次推进仍验证会话令牌、generation和stateVersion。重复推进不会替玩家行动，重来/退出/后台取消待执行任务，旧应答不能覆盖新练习。

正式恢复记录保护、本机私人标记隔离和减少动画继续有效。旧163变体保留在内部规则测试中，不再作为产品菜单或玩家完成任务的数量指标。

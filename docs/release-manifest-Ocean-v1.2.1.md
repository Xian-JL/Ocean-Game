> Socket Protocol：1.8

## 发布定位

Ocean-v1.2.1 是 v1.2 的前端体验补丁。它保留 1v1 联机、1v1 人机、三人 FFA、三档动态地图和全部服务器权威规则，只增加独立音量控制并调整对战信息布局。仍采用单体 Node.js + Socket.IO 架构，不增加数据库、外部 AI 或付费服务。

## v1.2.1 新增能力

- “帮助 → 声音”提供音效、背景音乐两个 0～100 音量滑杆，拖动即生效。
- 两项音量与两个开关互相独立，并分别保存在当前浏览器；音量为 0 不会篡改开关状态。
- 音效仍由 Web Audio 本地合成；背景音乐仍读取 `public/assets/audio/music/ocean-theme.mp3`，素材缺失不会阻断游戏。
- P05 将“战况 / 私人情报 / 系统”频道放入地图主列，紧邻全部地图下方，不受右侧行动面板高度影响。
- 桌面端保持地图主列与行动面板双列；窄屏依次显示地图、三频道、行动面板。
- 三频道的内容、历史、未读状态与信息隔离不变；O04 轻量可关闭实时播报也保持 v1.2 行为。

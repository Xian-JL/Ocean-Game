日期：2026-10-21。主规范为材料根目录 spec.md v1.3。

## 实际模型

初始实现前从当前线程元数据确认 gpt-6-astra。续作检测为 gpt-6.1-sol 后说明约束并暂停新增实现，用户明确允许当前 Sol 继续，已记录到 spec 1.3。检测前部分修正/测试迁移也是 Sol 执行，不把整轮工作记为全由 Astra 完成。复杂复核仍独立安排。

## 已实现

- 正式页面只加载 ocean.css；令牌、基础组件、页面、地图、战斗与断点分为六个样式层，旧版本样式保留追踪但不控制新版。
- 18个前端职责模块在私有应用作用域组合，无新增前端依赖，不暴露完整房间/部署到window。
- 首页、等待、部署、掷骰、战斗、最终齐射、结算复盘、五章教程与设置统一表面和排版。
- 战斗采用舰队、中央海图、行动区和统一指令台；选点只存草稿，唯一执行按钮提交。最终齐射先选鱼雷再确认。
- 摘要显示行动、来源、单格/区域锚点/行列、影响方、资源成本/剩余、条件风险及保密提示。
- 提交防重、稳定actionId、未知结果先同步、过期目标清理，保留原服务端权威。
- 保留三地图、三人同步独立结果、十行动、五种私人标记；敌图位置键改为实际玩家ID；安全快照补充原界面已使用的公开淘汰名单。
- 手机42px格和平移、四导航、互斥抽屉、动态指令台占位；resize重排、地图方向键、roving焦点、删除标记、单选器键盘、浮层焦点和减少动画。
- 复用原舰体、海面、SVG与特效；常态不贴旧强金属/状态光框。没有新增生图或玩家生图API。
- 内容哈希缓存版本由构建统一生成；产品仍1.6.1、规则1.8、Socket2.1。具体版本/文件哈希见build-manifest.json。

- 收尾修正：重复战斗结果仅作无浮层读屏播报，低高度保留风险说明；战斗反馈与终局复盘按单位实例ID显示摩托艇编号。

## 基础验证

`npm run acceptance`：452项，452通过，0失败，0跳过。含真实双客户端整局、隐藏结果、恢复、复盘、再来一局及新增控制台回归。日志在evidence/tests/final-acceptance.log。

所有原测试文件保留。37项旧视觉形状断言迁移；DOM/整局测试使用新摘要执行；新增9项防重、旧目标、键盘、标记隔离、鱼雷秘密确认、抽屉、三人目标和单位实例编号测试。详见test-migration.md/json。

真实本地浏览器已走创建人机→随机部署→准备→主动掷骰/同点重投→雷达选点→确认执行→反馈，并查看桌面/390×844模拟手机、行动抽屉及主题设置。视觉证据以evidence/visual清单为准。

## 启动与修改

`npm ci`后`npm start`，默认本机3000。修改client源文件后运行npm run build并重启服务、刷新页面；生成文件为public/js/app.js与public/css/ocean.css。组件参考可用node scripts/preview-design.js在本机3003查看。

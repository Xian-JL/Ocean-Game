# 信息与装饰取舍

常态使用实体表面、单层细边界、明确对齐、正常字号。海图保留现有舰体、真实海面、坐标和局部事件；普通控制面板不连续发光或循环扫描。

| 页面 | 保留的主信息 | 合并/渐进展开 | 移除的冗余 |
| --- | --- | --- | --- |
| 首页 | 名称、模式、地图、昵称、创建/加入、教程 | 人机时展开难度；有会话才有恢复条 | 主标题的多层光晕、反复英文口号、战斗资源预加载 |
| 等待 | 房间码、邀请、席位、在线状态 | 邀请链接弱化，规则在帮助 | 空匹配进度、无依据倒计时、每席大框套小框 |
| 部署 | 海图、完整名称清单、当前对象、合法性、计时、准备 | 操作工具成组；手机清单在有限区域滚动 | 单位卡多层边框、冗余提示重复占据海图空间 |
| 掷骰 | 真人主动操作、服务端点数、轮次、先手 | 历史紧凑列表 | 整屏光效、持续旋转、额外客户端随机 |
| 战斗状态栏 | 当前回合/行动者、时间、连接、菜单 | 房间详情窄屏弱化 | 通用网站导航、舱壁横幅、重复双方大名牌 |
| 舰队区 | 航母优先、每个单位名称/HP/状态、有效诱饵 | 资源明细 details；中屏/手机抽屉 | 与行动区相同的七组行动卡 |
| 行动区 | 可用行动、目标方式、当前行动规则 | 受限/耗尽分组一步展开，原因随项显示 | 把十个动作都做成常态大型发光卡、另一套确认按钮 |
| 海图 | 单张当前地图、玩家标签、坐标、合法范围、目标、权限内事实 | 私人标记工具只在标记模式显示，历史情报在对应频道 | 整板透视、五区驾驶舱框、多份海图并排缩小 |
| 指令台 | 正式行动名、目标、实际影响方、成本、相关风险、唯一执行 | 辅助工具按布局收敛 | 选点即弹模态、多处独立草稿、执行前不同步的确认入口 |
| 最近反馈/日志 | 依法可见结果与己方实际变化 | 稳定槽位，详情可展开；历史滚动位置保留 | 切图重播冲击/声音、多条相同结果 Toast |
| 最终齐射 | 己方鱼雷坐标、秘密提交状态、确认引爆 | 本轮参与状态 | 普通攻击工具、对方秘密选择、虚构普通行动计时 |
| 结算 | 结果/原因、最终航母HP、再来、离开、复盘 | 详细复盘在后续内容 | 战力评分、等待庆祝动画才能操作、重复结果区 |
| 教程/设置/错误 | 当前任务/选项、真实状态、下一步 | 按章节/类别组织长解释 | 科技词替代错误、误导玩法的演示、不可读小字 |

高画质和减少动画的事实一致。普通卡片阴影关闭，浮层统一使用柔和阴影。舰体与海面按现有素材复用，未强制采用60项旧UI贴图。

设计源为 `client/styles/` 与对应页面模块；运行截图是布局的实际参考。完整跨主题视觉、一致性与性能判定待独立验收，不以本文自行认定全部满足。

# Ocean-v1.4 发布清单

- 产品：Ocean-v1.4
- npm：1.4.0
- 规则：rule-v1.8
- 页面流程：page-flow-v2.1
- Socket：2.1
- 音效清单：沿用 v1.3.3.2 / 3.1
- UI：D 方案——真实海面、隐形坐标、局部网格、战术准线

## 本版变化

- 正式对战地图使用无信息的俯视真实海面。
- 现有 10×10、12×12、15×15 坐标按钮保留为隐形吸附层。
- 鼠标悬停和键盘聚焦显示十字准线、行列刻度、坐标标签及 5×5 局部网格。
- 选择行动后显示合法范围；选择目标后显示原有范围预览。
- 正式对战一次只显示一张近全屏主地图，己方与各敌方海域通过顶部标签切换。
- 行动面板与战况/私人情报/系统消息移动到右侧覆盖侧栏；手机端转换为底部抽屉。
- 两个侧栏互斥，选择普通行动后自动收起，点击遮罩或按 `Esc` 可关闭。
- 三人局保留两张独立敌方地图和同步目标预览。
- 三套主题分别覆盖海面、坐标与控制台；手机端、高对比度和减少动画均有降级方案。

## 明确未修改

- rule-v1.8 的单位、生命值、伤害、弹药、胜负与行动规则。
- page-flow-v2.1 的教程、三档人机、房间和复盘流程。
- Socket 2.1 的事件、状态结构、身份绑定与安全投影。
- 五种私人标记的本地存储和右键/手机长按删除。
- 三人一次行动同时作用于两名对手。
- v1.3.3.2 的 OGG/MP3 双格式音效与隐藏武器保密策略。

## 验收重点

- 10×10、12×12、15×15 均保持正确行列数量和坐标。
- 悬停/键盘聚焦不会触发行动，也不会写入状态。
- 海面背景不能携带任何隐藏目标信息。
- 合法范围、目标预览、五类私人标记和三人同步预览仍可辨认。
- 手机一次只显示当前地图，触控目标尺寸不因桌面布局变化而缩小。

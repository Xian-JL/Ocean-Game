# 《海战 OCEAN》postlaunch-v0.7.0 发布清单

> 版本：0.7.0  
> 阶段：postlaunch-v0.7.0  
> UI：UI Design v0.7.0  
> 游戏规则：rule-v1.4（与 v0.6.2 相同）  
> 页面流程逻辑：page-flow-v1.4（与 v0.6.2 相同）  
> Socket：1.5 / socket-protocol-v0.8

## 1. 定位

v0.7.0 是 UI 重构系列第一版，只调整表现层，不改变 v0.6.2 的游戏行为。

## 2. 已完成

- 新增统一 CSS Design Tokens；
- 全局 Header / Footer 现代化；
- 连接状态、帮助入口与响应式导航重构；
- 首页改为现代应用入口，支持 2 人 / 3 人分段选择；
- 创建房间与加入房间操作层级重构；
- 恢复上次对局卡片重构；
- 等待房间改为房间码主卡 + 玩家席位卡；
- 2 人 / 3 人等待房间使用同一响应式布局；
- Toast、Modal、Tooltip、Loading 与 Focus 状态统一；
- 游戏说明补充 v0.6.2 三人双目标回合、独立敌图、直升机与终局鱼雷例外；
- 详细规则集中到帮助弹窗，主页面减少解释性段落。

## 3. 明确未修改

- 所有舰船与弹药数值；
- 所有行动合法性与伤害结算；
- 首次雷达规则；
- 三人每回合分别操作两名敌人的规则；
- 90 秒共享回合计时；
- B/C 独立敌方地图数据；
- 直升机多目标规则；
- 最终鱼雷多目标规则；
- 瘫痪、淘汰、投降、断线重连和胜负判定；
- Actor / Defender / Observer 隐藏信息边界。

## 4. 后续

- v0.7.1：部署页与地图组件；
- v0.7.2：对战三地图布局、折叠和三人回合进度；
- v0.7.3+：行动、反馈、特殊阶段、SVG、美术与最终响应式验收。

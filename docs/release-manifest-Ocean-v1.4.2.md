# Ocean-v1.4.2 发布清单

- 产品：Ocean-v1.4.2
- npm：1.4.2
- 规则：rule-v1.8（未修改）
- 页面流程：page-flow-v2.1（未修改）
- Socket：2.1（未修改）
- UI：三主题完整适配、方形战术海面

## 本版修复

- 极地寒光的输入框、模式与地图选择器、部署卡片、舰队列表、私人标记、行动侧栏和战况面板统一使用浅色组件表面与深色文字。
- 黄昏余晖为相同组件提供暖棕色表面，消除残留的深海蓝灰控件。
- 主题激活态、次级按钮、占位文字与部署网格分别设置可读颜色，不再仅切换字体颜色。
- 桌面对战海面由全宽横幅改为方形战区，背景只覆盖坐标盘，不再在大背景中央悬浮一块小地图。
- 10×10、12×12、15×15 使用相同方形布局并随可用视口放大；手机端继续使用 42px 触控格与横向滚动。
- 保留减少动画、强制高对比和主题本地持久化能力。

## 明确未修改

- v1.4.1 驱逐舰射程耗尽与最终鱼雷齐射修复。
- 单位、武器、伤害、弹药、部署、回合、胜负和隐藏信息规则。
- 三档人机、五章教程、房间、重连、复盘、私人标记类型与音效。
- Socket 2.1 的事件名称、载荷和安全玩家视图。

## 验收重点

- 三套主题分别检查首页、部署和对战，确保同一面板内没有浅色文字叠在浅色底或深色文字叠在深色底。
- 在 10×10、12×12、15×15 下确认海面边缘与坐标盘边缘一致，地图尽量利用桌面可用高度。
- 在不超过 900px 的视口确认地图仍可横向滚动，行动与消息抽屉保持可用。

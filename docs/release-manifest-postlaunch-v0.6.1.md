# 海战 OCEAN · postlaunch-v0.6.1 发布清单

## 1. 发布定位

- 应用版本：`0.6.1`
- 发布阶段：`postlaunch-v0.6.1`
- 规则版本：`rule-v1.3`
- Socket 协议：`1.4`
- Node.js：`>=24`，推荐 `.node-version` 指定的 `24.19.0`
- 部署目标：GitHub `main` → Render

本版本不增加新的武器或胜负规则，目标是把 v0.6 已实现的双人/三人规则与前端显示、协议元数据、信息可见性和赛后生命周期完全对齐。

## 2. 一致性修复

1. 首页、规则弹窗和部署页不再显示旧版版本号、协议号、棋盘尺寸、舰队数量、驱逐舰范围或潜射导弹数量等历史信息。
2. HTTP `/api/health`、`/api/status`、Socket `system:ready` 与浏览器 `GameData.RELEASE` 统一使用同一发布基线。
3. 探测弹和雷达扫描的“有/无信号”结果仅行动方可见；公共记录保留行动名称、目标玩家和公开区域，不包含布尔结果。
4. 公共行动记录包含 `defenderId`，三人局公开战报可以准确显示行动方与防守方。
5. 三人局 FINISHED 后一名玩家离开时，房间保留所有其他席位并回到 WAITING；若原房主离开，则把房主交给剩余席位中的第一名玩家。
6. 再来一局状态按 `requestedPlayerIds` 对每个其他玩家分别显示。
7. 当前用户界面和服务器错误提示中与多人规则冲突的“双方/对方/两份部署”表述已泛化。

## 3. 回归重点

- 2 人完整对局仍按原有规则执行；
- 3 人房必须坐满 3 席才进入部署；
- 三人攻击必须指定仍在局目标玩家；
- 驱逐舰重复坐标按“目标玩家 + 坐标”隔离；
- 航母沉没、投降或三次连续行动超时在三人局先出局，直到只剩一名仍在局玩家；
- 潜射导弹、核弹不向行动方报告命中结果；
- 探测弹、雷达布尔结果不泄露给防守方或第三方；
- 终局鱼雷在所有仍在局玩家提交后同时结算；
- 三人赛后离开和再来一局不会错误删除或错误标注其他席位。

## 4. 发布前命令

```powershell
node -v
npm ci
npm run acceptance
git status --short
```

必须使用 Node 24+。验收全部通过后再提交并推送到 GitHub `main`，由 Render 自动部署。

## 5. 线上检查

部署为 Live 后检查：

- `/api/health` 的 `stage` 为 `postlaunch-v0.6.1`，`socketProtocol` 为 `1.4`；
- 首页 Footer 显示 `postlaunch-v0.6.1` 与协议 `1.4`；
- 规则弹窗显示 `RULE v1.3`；
- 首页与部署页显示 12×12、8 个作战单位；
- 创建 2 人房与 3 人房均正常；
- 三人公开战报能区分行动方与防守方；
- 探测弹/雷达结果只在行动方页面显示；
- 三人赛后一人离开后其余两名玩家仍留在房间。

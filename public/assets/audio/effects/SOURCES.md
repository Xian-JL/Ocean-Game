# Ocean v1.3.3 音效素材说明

本目录内容来自用户为 v1.3.3 筛选并提供的素材包。运行时文件位于 `source/`，游戏不联网获取音效。

主要 Freesound 来源：

- K-55 Artillery：https://freesound.org/s/184365/
- BGM-71 TOW Missile Launch：https://freesound.org/people/qubodup/sounds/67541/
- Underwater Explosion：https://freesound.org/people/cubix/sounds/124544/
- Sonar Ping：https://freesound.org/people/SamsterBirdies/sounds/539957/
- Sonar Sweep Beep：https://freesound.org/people/SamsterBirdies/sounds/371178/
- Submarine Sonar：https://freesound.org/people/Breviceps/sounds/493162/
- Helicopter Rotor Loop：https://freesound.org/people/qubodup/sounds/187681/
- Retro Pirate Cannon Shot：https://freesound.org/people/LilMati/sounds/515801/
- Water Splash 1/2：https://freesound.org/people/qubodup/sounds/210428/ 和 https://freesound.org/people/qubodup/sounds/210427/
- Kenney Interface Sounds：https://kenney.nl/assets/interface-sounds

其余素材保留上传时的原始文件名，便于根据用户下载记录追溯。`01.ogg` 与 `1.ogg` 是为浏览器兼容性由同目录原始 AIFF/FLAC 文件转码得到的运行副本。

# 海战 OCEAN · Ocean-v1.2.7

`Ocean-v1.2.7` 基于已通过验收的 `Ocean-v1.2.6`，本版只进行手机端 UI 适配。战斗规则、单位数值、地图参数、1v1 联机、1v1 人机、三人 FFA、服务器结算与 Socket 协议均保持不变。

## 正式版本基线

- 产品名称：Ocean-v1.2.7
- npm version：1.2.7
- 战斗规则：rule-v1.8
- 页面流程：page-flow-v2.0
- Socket Protocol：2.0
- 稳定代码基线：Ocean-v1.2.6
- 棋盘：10×10 / 12×12 / 15×15（默认 12×12）
- 模式：1v1 联机 / 1v1 人机 / 3 人 FFA
- Node.js：>=24

## v1.2.7 手机端 UI 更新

- 页面支持刘海屏与底部手势安全区，并使用动态视口高度，软键盘弹出时不会遮住主要表单。
- 首页、等待页、部署页、掷骰页、战斗页、终局页和声音/规则弹窗统一适配 320～700 px 窄屏。
- 手机地图固定保留 42 px 触控格并横向滑动；移动端不再叠加桌面 0.85 / 0.9 / 0.765 显示缩放，避免触控格过小。桌面缩放逻辑保持不变。
- 战斗状态栏不再与地图切换条重叠；地图标签保持在顶部，行动面板以底部抽屉显示。
- 五类私人标记在窄屏中横向滑动；点击添加，电脑右键或手机长按 550 ms 删除，滑动地图不会误触删除。
- 实时播报、确认框、规则和声音设置使用手机宽度与安全区，仍可点击关闭。
- 规则继续使用 `rule-v1.8`，页面流程继续使用 `page-flow-v2.0`，Socket Protocol 继续为 `2.0`。

## 声音资源

音效由浏览器实时合成，不需要准备音效文件。点击页面顶部的“音效”或“背景音乐”按钮会打开独立声音设置层，可分别开关并以 0～100 调整音量，偏好保存在当前浏览器。

若要启用背景音乐，请将拥有合法使用权的 MP3 命名为 `ocean-theme.mp3`，放入：

```text
public/assets/audio/music/ocean-theme.mp3
```

没有该文件时游戏和合成音效仍可正常运行。由 v1.2.6 升级时，应把原有同名音乐文件原样复制到 v1.2.7 的相同路径。

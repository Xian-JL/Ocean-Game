# 海战 OCEAN · Ocean-v1.2.6

`Ocean-v1.2.6` 基于已通过验收的 `Ocean-v1.2.4`。本版加入五类灵活私人标记、右键删除、三人每回合一次同步行动，以及三人/15×15 地图显示缩放。1v1 联机、1v1 人机、三人 FFA、三档动态地图及既有战斗数值继续保留。

## 正式版本基线

- 产品名称：Ocean-v1.2.6
- npm version：1.2.6
- 战斗规则：rule-v1.8
- 页面流程：page-flow-v2.0
- Socket Protocol：2.0
- 稳定代码基线：Ocean-v1.2.4
- 棋盘：10×10 / 12×12 / 15×15（默认 12×12）
- 模式：1v1 联机 / 1v1 人机 / 3 人 FFA
- Node.js：>=24

## v1.2.6 更新

- 每张敌方地图上方提供“确定有、水面有、水面无、水下有、水下无”五种本机私人标记；左键按当前类型写入，右键删除已有私人标记，自动命中/未命中标记不受影响。
- 三人局每个玩家回合只提交一次行动。同一坐标、区域、行或列同时作用于两名仍在局敌人；两名防守方分别结算，弹药、使用次数和行动方自损只结算一次。
- 三人雷达在首回合以同一区域同时扫描两名敌人，并只向行动方返回按敌人区分的两份结果。
- 三人公共记录隐藏两名防守方的具体结果；行动方与每名防守方只收到各自有权查看的信息。
- 三人战斗地图显示比例为 0.85；15×15 地图显示比例为 0.9；三人 15×15 叠加为 0.765，坐标与格子整体缩放。
- 驱逐舰同步攻击后的坐标全局锁定，不能通过切换敌方地图重复攻击。

## 声音资源

音效由浏览器实时合成，不需要准备音效文件。点击页面顶部的“音效”或“背景音乐”按钮会打开独立声音设置层，可分别开关并以 0～100 调整音量，偏好保存在当前浏览器。

若要启用背景音乐，请将拥有合法使用权的 MP3 命名为 `ocean-theme.mp3`，放入：

```text
public/assets/audio/music/ocean-theme.mp3
```

没有该文件时游戏和合成音效仍可正常运行。

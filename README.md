# 海战 OCEAN · Ocean-v1.3.3.2

`Ocean-v1.3.3.2` 完成两个阶段：以 OGG/MP3 双格式清单修复 Render 音效兼容问题，并将对战页升级为原创航母指挥舱 2.5D 框架。战斗规则、教程、人机难度、地图参数、联机模式、主题系统、私人标记、消息保密和服务器结算均不改变。

## 继承自 v1.3.2：个性化主题与强调色

- 顶部新增“个性化设置”入口，独立弹窗提供**三套界面主题**（深海暗夜 / 极地寒光 / 黄昏余晖）与**五种强调色**（离子青 / 荣耀金 / 翡翠绿 / 赤焰红 / 极光紫）。
- 主题与强调色只保存在当前浏览器（`ocean.theme.v1` / `ocean.accent.v1`），不影响对局、服务器结算与信息投影；不同标签页独立生效。
- 首帧由 `theme-bootstrap.js` 同步应用已保存设置，避免刷新时主题闪烁；CSS 采用“色板 → 语义 → 旧变量别名”三层令牌，主题切换无需改动任何组件样式。
- 强调色作用于边框、图标与激活状态；三套主题均通过基础可读性检查，保留“减少动画”等既有可访问性设置。

## v1.3.3 真实素材音效

- 战斗、部署、私人标记、教程、房间和结算操作改用本地真实音频素材，并保留合成回退。
- 沿用 `effectsBus / musicBus → DynamicsCompressor → masterGain → destination` 主音频链及同时最多 12 个效果的并发限制。
- 潜射导弹、核弹、震爆弹只使用固定“已执行”组合，不按命中结果改变，避免音效泄露情报。
- 音频库内部版本升级为 `3.0`；既有音效开关、音效音量、音乐开关和音乐音量设置不变。

## v1.3.1 差异化音效（上一版特性，保留）

- 十种战斗行动分别使用独立的行动音色：两型驱逐舰、海盗船、摩托艇、潜射导弹、核弹、震爆弹、探测弹、直升机和雷达均可听辨。
- 部署、移动、旋转、移除、撤销、随机部署、准备、掷骰、标记、锁定目标、房间操作、教程反馈和胜负状态均使用对应音效。
- 只有合法且实际生效的本地操作才播放对应声音；需服务器确认的操作在确认成功后播放。

## v1.3 完整交互教程

- 首页和“游戏说明”均可进入教程；教程在浏览器本地运行，不创建房间，不等待服务器，也不改动线上对局。
- 五章依次训练：秘密部署、攻击与单格伤害、雷达与私人标记、隐藏武器与分角色播报、最终指挥考核。
- 每章包含明确目标、可点击模拟地图、即时纠错和规则解释；错误操作不会跳过任务。
- 只在当前浏览器保存已完成章节，不保存模拟布局或任何真实对局情报。
- 完成后可一键回到首页并预选“新手人机、12×12”，也可随时返回任一章节复习。
- 手机端保留 42px 触控格、横向地图滑动、安全区和章节横向导航。

## v1.3 三档人机难度

| 难度 | 决策方式 | 适合玩家 |
| --- | --- | --- |
| 新手 | 在全部合法行动和合法目标中随机选择；仍遵守首回合雷达、范围和资源限制 | 第一次完整对局 |
| 标准 | 沿用 v1.2.7 策略，结合公开命中、未命中和己方侦察结果计算目标优先级 | 已熟悉基础规则 |
| 专家 | 在标准策略上加入否定情报排除、相邻命中方向延伸、扫描去重、武器与剩余资源权衡 | 希望获得稳定挑战 |

三档机器人都只接收与真人客户端同级的安全玩家视图。服务器不会把敌方隐藏部署、未公开单位类型或秘密结算结果交给机器人。难度只改变决策，不改变伤害、生命值、弹药、地图或机器人作弊权限。

机器人仍固定用于 1v1；本版不加入三人人机。玩家创建人机房时难度与房间一起锁定，并在部署、重连、对局、终局鱼雷和再来一局中保持一致。

## 声音资源

所有操作音效继续由浏览器实时合成，不需要额外音效文件。背景音乐文件仍为：

```text
public/assets/audio/music/ocean-theme.mp3
```

若新版本目录中没有该文件，请从上一正式版的相同相对路径原样复制。缺少音乐文件不会阻止游戏或内置音效运行。

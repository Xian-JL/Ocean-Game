# 海战 OCEAN · Ocean-v1.6.4

## 本版内容

v1.6.4专注前端：改善十槽名称/资源与可触摸说明、实际来源舰肖像、坐标定位/固定坐标轴/视窗概览、缩放锚点、移动端和十行动形态。全部后端、规则与安全模型保持；训练课程、结算与复盘不扩展。

当前工作区已实现 UI SPEC 2.0“黑潮军械库”：电影感舰坞、原创舰徽与刻印武器、中央海图和底部军械台；支持10×10、12×12、15×15海图，2人联机、人机1v1、3人FFA。玩法仍为rule-v1.8，页面流程page-flow-v2.1，Socket协议2.1。

训练营面向核心战斗体验：四步快速上手、十种行动一键试射，以及不计时的自由练习。舰队预先部署，陪练自动行动，玩家只需选择行动、瞄准、确认与查看结果。调试目录、角色切换、虚拟时钟和故障模拟不再作为玩家功能；训练与正式房间隔离。

恢复原有爆炸、水花、尾迹、舰体状态和海域材质，并增强轨迹、冲击环与扫描；流畅模式保留动作形态，减少动画保留静态事实。

## 安装与运行

需要Node.js 24或更新版本。进入目录执行：

    npm ci
    npm start

访问 http://127.0.0.1:3000 。Windows也可双击start.cmd，首次自动安装运行依赖。仅运行可执行npm ci --omit=dev；测试需要完整安装开发依赖。node_modules不随精简项目保留，可随时重建。

局域网执行npm run start:lan，公开服务执行npm run start:public。Render配置见render.yaml。房间使用内存存储，服务重启后不能恢复；公开部署的管理令牌说明见原部署文档。训练进度保存在本机浏览器。

## 开发与验证

修改client源模块，npm run build生成app.js和ocean.css；不要只改生成文件。npm run acceptance执行音频、语法和完整回归。

[本版发布与验证](docs/releases/v1.6.4/README.md)记录实际测试、构建与清理。当前[spec.md](spec.md)对应 UI SPEC 2.0，方向为暗黑军械库×战争史诗。[开发交接与验收材料](docs/ui-v2/README.md)记录当前实现、基础验证和未测项。本次作为v1.6.4发布。规范、产品v1.6.4与规则v1.8分别编号。发布不表示真机、全兼容矩阵、正式性能及完整独立验收的未测项已通过。

# 海战 OCEAN · postlaunch-v0.6.2

`postlaunch-v0.6.2` 基于稳定版 `postlaunch-v0.6.1` 修订三人回合与终局鱼雷规则。现行规则基线为 `rule-v1.4`，Socket 协议为 `1.5`。

## v0.6.2 核心变化

- 三人局中，一名玩家的正常回合需要分别对每名仍在局敌方玩家完成一次操作；A 面对仍在局的 B、C 时，需要分别对 B、C 各完成一次操作，B、C 的回合同理；
- 两次操作属于同一个玩家回合，共享同一个 90 秒截止时间，第一项操作后不重置计时、不增加回合号；
- 两次操作可以采用任意合法组合，也可以在原规则允许时由同一单位连续发动；每次仍独立执行弹药、范围、伤害、隐藏信息与行动来源限制；
- 每名敌方玩家拥有独立敌方地图记录；对 B 的命中/未命中、驱逐舰已攻击坐标、潜射/核弹标记与侦察记录不会写入 C 的地图；
- 直升机扫射为三人回合例外：必须作为本回合首个且唯一行动，同一行/列同时在所有仍在局敌方地图上独立结算，一次性完成整个回合；
- 每名玩家首个正常回合的第一项操作仍强制使用雷达；三人局雷达只作用于所选一名敌人，随后同一回合继续对另一名敌人操作；
- 三人终局手动鱼雷改为多目标：每轮选择一枚己方未引爆诱饵鱼雷后，该坐标同时攻击其他所有仍在局玩家的同名坐标；
- 三人回合进度加入安全状态字段：`requiredTargetPlayerIds`、`completedTargetPlayerIds`、`remainingTargetPlayerIds`、`actionCount`；
- 多目标直升机行动记录加入 `defenderIds` 与按防守方拆分的逐格结果，继续保持行动方/防守方/第三方的信息分级。

## 当前规则基线

- 棋盘：12×12；
- 房间：2 人或 3 人 FFA；
- 驱逐舰Ⅰ：3 HP，攻击范围沿舰身 11 × 垂直 7；
- 驱逐舰Ⅱ：3 HP，攻击范围沿舰身 10 × 垂直 8；
- 潜艇：2 HP，潜射导弹 4 枚；
- 核潜艇：3 HP，核弹 2、震爆弹 1、探测弹 1；
- 摩托艇：2 艘；
- 航空母舰：6 HP，每名玩家首个正常回合第一项操作强制 4×4 雷达扫描；
- 直升机扫射：1 次，两艘己方驱逐舰均沉没后解锁；三人局同时作用于所有仍在局敌人；
- 诱饵鱼雷：3 枚；
- 所有仍在局玩家永久失去正常攻击手段后进入逐轮手动终局鱼雷引爆；三人局每枚选中鱼雷同时攻击其他全部仍在局玩家。

## 三人回合示例

A、B、C 均仍在局时，A 的一个回合可以是：

```text
A → B：驱逐舰Ⅰ冲撞
A → C：潜射导弹
随后轮到 B
```

也可以是：

```text
A → B：震爆弹
A → C：核弹
随后轮到 B
```

直升机是例外：

```text
A：直升机扫射 J 行
   ├─ 同时结算 B 的 J 行
   └─ 同时结算 C 的 J 行
随后轮到 B
```

终局鱼雷是另一项多目标例外：

```text
A 选择己方 G10 诱饵鱼雷
   ├─ 同时攻击 B 的 G10
   └─ 同时攻击 C 的 G10
```

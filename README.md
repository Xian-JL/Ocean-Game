# 海战 OCEAN · postlaunch-v0.6.1

`postlaunch-v0.6.1` 是基于 `postlaunch-v0.6` 的前后端一致性修订版。核心游戏规则继续使用 `rule-v1.3`：12×12 海域、双人/三人房间、三人目标选择与出局轮转、服务器权威结算和分级战报。

## v0.6.1 修订内容

- 统一前端、HTTP 健康接口和 Socket 握手的发布信息：游戏版本 `0.6.1`、阶段 `postlaunch-v0.6.1`、规则 `v1.3`、Socket 协议 `1.4`；
- 首页、部署页和规则弹窗统一为 12×12、8 个作战单位、3 枚诱饵鱼雷、10 项行动以及当前舰船/弹药数值；
- 驱逐舰Ⅰ/Ⅱ前端说明与后端一致：命中存活作战单位时目标 −1、自身 −0.5；命中诱饵时自身 −1；未命中不自损；
- 探测弹与雷达扫描的布尔结果只发给行动方，防守方和第三方只看到公开行动，不再获得探测结果；
- 公共行动记录增加 `defenderId`，三人局第三方可以明确知道“谁对谁”执行了公开行动；
- 修复三人局赛后一名玩家离开时误丢弃另一名剩余玩家的问题；
- 再来一局页面按所有其他席位分别显示申请状态，不再用单一“对手”推断；
- 双人时代遗留的“双方/对方/两份部署”等当前界面与服务器提示改为兼容 2～3 人的表述；
- 客户端收到 `system:ready` 后会核对页面版本与服务器版本，若不一致会提示强制刷新。

## 当前规则基线

- 棋盘：12×12；
- 房间：2 人或 3 人 FFA；
- 驱逐舰Ⅰ：3 HP，攻击范围沿舰身 11 × 垂直 7；
- 驱逐舰Ⅱ：3 HP，攻击范围沿舰身 10 × 垂直 8；
- 潜艇：2 HP，潜射导弹 4 枚；
- 核潜艇：3 HP，核弹 2、震爆弹 1、探测弹 1；
- 摩托艇：2 艘；
- 航空母舰：6 HP，首回合强制 4×4 雷达扫描；
- 诱饵鱼雷：3 枚；
- 所有仍在局玩家永久失去正常攻击手段后进入逐轮手动终局鱼雷引爆。

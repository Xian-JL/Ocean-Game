# 海战 OCEAN · Ocean-v1.5

`Ocean-v1.5` 按舰桥概念图重构正式战斗页：顶部状态条、中央立体战术沙盘、左侧三类情报入口、右侧常驻行动台和底部连续控制台组成统一的航母指挥舱。规则、数值、Socket 2.1、信息投影、人机、三人模式和移动端操作全部继承 v1.4.2.2。

## v1.5 舰桥立体战术沙盘

- 桌面正式对战改为全屏航母舰桥结构，通用网站顶栏在战斗中让位于房间、回合、倒计时和双方状态组成的指挥条。
- 当前地图以轻度透视、海图纹理、战术网格和舰种 SVG 轮廓形成可点击的立体沙盘；10×10、12×12、15×15 均按可用宽高缩放。
- 左侧固定战斗日志、情报信息、系统消息三个入口；右侧行动与舰队状态常驻，不再要求桌面玩家先打开覆盖抽屉。
- 底部控制台提供综合/水面/潜层显示、五种私人标记、行动确认、取消和舰桥菜单。
- 战术视层只改变己方单位的视觉强调，不进入 Socket 请求，也不产生新的敌方情报。
- 900px 及以下继续使用 v1.4.2.2 的地图标签和底部抽屉，避免立体透视影响触控命中。
- v1.5 使用现有舰桥、海面和 SVG 图标作为正式占位素材；精细舰船与驾驶舱美术留待 v1.5.1 替换。

## v1.4.2.2 地图切换条修复

- 桌面端回合状态栏与地图切换条使用互不重叠的粘性位置，页面滚动后仍可完整看到“己方 / 敌方”按钮。
- 战斗外框改用 `overflow: clip` 保留圆角裁切，同时避免 `overflow: hidden` 破坏粘性定位参照。
- 手机端原有顶部地图标签规则不变；地图尺寸、行动侧栏、三套主题和游戏规则均未修改。

## v1.4.2.1 定点修复

- 诱饵鱼雷状态与赛后复盘的分母改为读取当前对局实际鱼雷总数，10×10、12×12、15×15 分别正确显示 2、3、5。
- 雷达选择坐标统一说明为扫描区域的“左上起始格”，不再与震爆弹、探测弹所使用的“中心格”混淆。
- 桌面对战入口移除多余顶距、压缩航母地平线与地图标签间距，并根据视口高度限制方形战区大小，使主要内容能在首屏完整呈现。
- 行动和消息侧栏按当前视口高度限制外框与内部滚动区，避免底部越界；手机端底部抽屉规则保持不变。
- 极地寒光配色未修改；规则、数值、Socket 协议、AI、教程与音效均保持 v1.4.2 基线。

## v1.4.2 主题与战术海面修复

- 极地寒光不再只改变字体：输入框、模式选择、地图尺寸、部署面板、舰队列表、私人标记、行动与消息抽屉均使用完整浅色组件体系。
- 黄昏余晖同步使用暖棕表面和对应激活态，消除局部残留的深海蓝灰背景。
- 部署地图在极地寒光下使用浅色海图与深色坐标，保留单位、合法位置和错误状态的原有语义色。
- 桌面对战背景只覆盖方形坐标盘，不再使用全宽海面横幅承载中央小地图。
- 方形战区按可用视口高度自动放大，10×10、12×12、15×15 都填满同一战术区域；手机仍保留 42px 触控格与横向滚动。
- 强制高对比模式和主题本地保存继续有效，未修改规则、协议、信息边界或音效。

## v1.4.1 终局死锁修复

- 终局攻击能力检查现在与正式回合合法目标检查使用同一目标玩家上下文。
- 驱逐舰虽然仍存活，但其射程内所有坐标均已使用时，不再被误判为仍有攻击手段。
- 当所有仍在局玩家都没有其他攻击手段时，服务器立即进入 `FINAL_SALVO`，不会让双方循环待命。
- 同时覆盖仅一方由“驱逐舰射程耗尽”失去攻击能力，以及双方都由该原因失去攻击能力的情况。
- 不修改驱逐舰范围、共享坐标、伤害、自损、弹药、鱼雷齐射或信息保密规则。

## v1.4 真实海面与隐形坐标

- 对战地图使用无舰艇、无文字、无目标信息的俯视真实海面素材。
- 坐标按钮、合法范围、目标预览和服务器提交数据完全沿用原模型。
- 默认只显示极淡全局格线；悬停或键盘聚焦时显示十字准线、行列刻度、坐标标签和目标附近 5×5 局部网格。
- 选择武器后保留合法范围，选择目标后保留原范围预览；已知命中、未命中、导弹和五种私人标记继续覆盖在对应单元格上。
- 正式对战一次只显示一张接近全屏的主地图；己方与各敌方海域通过顶部标签切换，三人局仍保留独立记录和同步预览。
- “行动”和“消息”改为右侧覆盖边栏，不再永久挤压海面；手机端自动改为底部抽屉。
- 深海暗夜、极地寒光、黄昏余晖分别适配海面与战术线；手机、减少动画和高对比度模式保留专门降级。

## 继承自 v1.3.2：个性化主题与强调色

- 顶部新增“个性化设置”入口，独立弹窗提供**三套界面主题**（深海暗夜 / 极地寒光 / 黄昏余晖）与**五种强调色**（离子青 / 荣耀金 / 翡翠绿 / 赤焰红 / 极光紫）。
- 主题与强调色只保存在当前浏览器（`ocean.theme.v1` / `ocean.accent.v1`），不影响对局、服务器结算与信息投影；不同标签页独立生效。
- 首帧由 `theme-bootstrap.js` 同步应用已保存设置，避免刷新时主题闪烁；CSS 采用“色板 → 语义 → 旧变量别名”三层令牌，主题切换无需改动任何组件样式。
- 强调色作用于边框、图标与激活状态；三套主题均通过基础可读性检查，保留“减少动画”等既有可访问性设置。

## v1.3.3 真实素材音效

- 战斗、部署、私人标记、教程、房间和结算操作改用本地真实音频素材，并保留合成回退。
- 沿用 `effectsBus / musicBus → DynamicsCompressor → masterGain → destination` 主音频链及同时最多 12 个效果的并发限制。
- 潜射导弹、核弹、震爆弹只使用固定“已执行”组合，不按命中结果改变，避免音效泄露情报。
- 音频库内部版本升级为 `3.0`；既有音效开关、音效音量、音乐开关和音乐音量设置不变。

## v1.3.1 差异化音效（上一版特性，保留）

- 十种战斗行动分别使用独立的行动音色：两型驱逐舰、海盗船、摩托艇、潜射导弹、核弹、震爆弹、探测弹、直升机和雷达均可听辨。
- 部署、移动、旋转、移除、撤销、随机部署、准备、掷骰、标记、锁定目标、房间操作、教程反馈和胜负状态均使用对应音效。
- 只有合法且实际生效的本地操作才播放对应声音；需服务器确认的操作在确认成功后播放。

## v1.3 完整交互教程

- 首页和“游戏说明”均可进入教程；教程在浏览器本地运行，不创建房间，不等待服务器，也不改动线上对局。
- 五章依次训练：秘密部署、攻击与单格伤害、雷达与私人标记、隐藏武器与分角色播报、最终指挥考核。
- 每章包含明确目标、可点击模拟地图、即时纠错和规则解释；错误操作不会跳过任务。
- 只在当前浏览器保存已完成章节，不保存模拟布局或任何真实对局情报。
- 完成后可一键回到首页并预选“新手人机、12×12”，也可随时返回任一章节复习。
- 手机端保留 42px 触控格、横向地图滑动、安全区和章节横向导航。

## v1.3 三档人机难度

| 难度 | 决策方式 | 适合玩家 |
| --- | --- | --- |
| 新手 | 在全部合法行动和合法目标中随机选择；仍遵守首回合雷达、范围和资源限制 | 第一次完整对局 |
| 标准 | 沿用 v1.2.7 策略，结合公开命中、未命中和己方侦察结果计算目标优先级 | 已熟悉基础规则 |
| 专家 | 在标准策略上加入否定情报排除、相邻命中方向延伸、扫描去重、武器与剩余资源权衡 | 希望获得稳定挑战 |

三档机器人都只接收与真人客户端同级的安全玩家视图。服务器不会把敌方隐藏部署、未公开单位类型或秘密结算结果交给机器人。难度只改变决策，不改变伤害、生命值、弹药、地图或机器人作弊权限。

机器人仍固定用于 1v1；本版不加入三人人机。玩家创建人机房时难度与房间一起锁定，并在部署、重连、对局、终局鱼雷和再来一局中保持一致。

## 本机运行

```powershell
Set-Location "E:\University\University_2.5\Ocean\Ocean-v1.5"
npm ci
npm start
```

浏览器打开 `http://127.0.0.1:3000`。

## 正式验收

```powershell
npm run acceptance
```

验收包含语法检查、完整规则回归、三档人机决策、五章教程状态机、双客户端整局、重连、手机端、发布一致性、真实海面、隐形坐标、个性化主题与音效引擎检查。

## 声音资源

操作音效继续使用 v1.3.3.2 已冻结的 OGG/MP3 双格式本地素材，并保留浏览器合成回退。背景音乐文件仍为：

```text
public/assets/audio/music/ocean-theme.mp3
```

若新版本目录中没有该文件，请从上一正式版的相同相对路径原样复制。缺少音乐文件不会阻止游戏或内置音效运行。
